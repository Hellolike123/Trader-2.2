## ADDED Requirements

### Requirement: 复盘面板新增主力行为段落
复盘输出 SHALL 在「分时走势与大单回溯」和「五层打分」之间新增「主力行为」段落，展示主力行为阶段判断和资金流向数据。

#### Scenario: 正常展示主力行为信息
- **WHEN** 资金流向数据可用且阶段判断非 unknown
- **THEN** 输出包含：阶段名称（中文）、置信度、近5日累计净流入、今日净流入、价资关系、近期趋势符号、关键提示

#### Scenario: 资金流向数据不可用时
- **WHEN** 资金流向API不可用或数据不足
- **THEN** 输出一行简要说明"资金流向数据暂不可用"，不报错

#### Scenario: 阶段为派发或砸盘时增加警告
- **WHEN** 阶段判断为 distribution 或 markdown
- **THEN** 输出中包含警告提示，如"主力资金持续流出，谨慎追高"

### Requirement: 主力行为输出格式
输出 SHALL 遵守微信端纯文本规范：不使用Markdown标题/表格/粗体，使用emoji符号+普通文本分节。

#### Scenario: 吸筹期输出示例
- **WHEN** 阶段为 accumulation，置信度 0.6，5日净流入 +3200万
- **THEN** 输出格式为：
  ```
  💰 主力行为
  阶段：吸筹期（置信度 0.6）
  资金：近5日累计净流入 +3200万 ｜ 今日净流入 +800万
  关系：价跌资入，疑似洗盘
  趋势：↑↑↑↓↑（近5日，4流入1流出）
  提示：连续3日净流入，关注是否放量突破
  ```

#### Scenario: 派发期输出增加警告
- **WHEN** 阶段为 distribution
- **THEN** 输出末尾追加一行"⚠️ 主力资金持续流出，谨慎追高"

### Requirement: 近期趋势符号
系统 SHALL 用箭头符号序列展示近5日资金流向方向，↑表示净流入，↓表示净流出。

#### Scenario: 5日中有4日流入1日流出
- **WHEN** 近5日中4日 net_flow > 0，1日 net_flow < 0
- **THEN** 输出"↑↑↑↓↑（近5日，4流入1流出）"

#### Scenario: 5日全部流出
- **WHEN** 近5日全部 net_flow < 0
- **THEN** 输出"↓↓↓↓↓（近5日，5流出）"
