## Context

当前 stage_positioning.py 用 MA 排列 + MA250 位置判定四阶段。讨论结果 #16 要求改为威科夫量价关系为核心，#17 要求四层防护。

## Goals / Non-Goals

**Goals:**
- 量价关系作为四阶段判定核心
- MA 结构和 ATR 作为辅助
- 四层防护机制
- MA250 改为独立提醒层

**Non-Goals:**
- 不改变下游调用接口（assess_stage 签名不变）
- 不改变输出格式

## Decisions

### 1. 威科夫量价关系为核心

```
量价维度（权重 50%）:
  缩量横盘 → 蓄势
  放量上涨 → 主升
  放量不涨 → 派发
  放量下跌 → 衰退

MA 结构（权重 30%）:
  多头排列 → 偏主升
  空头排列 → 偏衰退
  收敛 → 偏蓄势

ATR 波动（权重 20%）:
  ATR 上升 → 阶段活跃（主升/衰退）
  ATR 下降 → 阶段收敛（蓄势/派发末期）
```

### 2. 四层防护

- 多日确认：连续 3 日信号一致才确认阶段转换
- 置信度评分：0-100%，<60% 保持上次阶段
- 交叉验证：威科夫判定后用缠论/动量做 sanity check
- 阶段锁定期：转换后锁定 5 天（强反向信号除外）

### 3. MA250 改为独立提醒

MA250 不参与阶段判定，只在输出时显示提醒（价格在年线下方时标注风险）。

## Risks / Trade-offs

**[量价判定精度]** 需要回测验证阈值
→ 先用简单规则上线，后续通过自校准优化

**[多日确认延迟]** 阶段转换会延迟 3 天
→ 这是预期行为，宁可慢不要错
