## Context

全量审计 8 个计算模块发现 19 个数学正确性 bug。核心问题是三个：HMM 状态标签排序后映射错误、缠论 MACD 返回值未写回、T0 ADX Wilder 平滑公式错误。这些问题不是边缘场景，而是影响每一笔分析的核心数学错误。

## Goals / Non-Goals

**Goals:**
- 修复全部 4 个严重数学错误（HMM 标签、MACD 透传、ADX 公式×2）
- 修复全部 9 个中等逻辑错误（Wyckoff 阈值、fusion 权重、chan_core 买点）
- 修复全部 6 个低优先级问题
- 确保所有修复有对应的测试用例

**Non-Goals:**
- 不重新设计算法（如不改用更复杂的 MACD 面积比较）
- 不新增功能
- 不改变外部 API 接口
- 不优化性能

## Decisions

### 1. HMM 标签修复：改标签字典 vs 改排序方向

**问题**：排序后 index 1=Range, index 2=Bear，但标签字典写反。

**决策**：修改标签字典，使 index 1=Range, index 2=Bear。

**理由**：
- 排序方向（mu 从高到低）语义正确：高均值=牛市，低均值=熊市
- 标签字典是静态常量，改起来风险最低
- 替代方案：改排序方向为从低到高，但会破坏 `order` 数组的其他引用

### 2. 缠论 MACD 透传：赋值返回值 vs 原地修改

**问题**：`_calc_macd(bars)` 创建副本计算后返回值被丢弃。

**决策**：改为 `bars = _calc_macd(bars)`。

**理由**：
- `_calc_macd` 内部已经做了 `[dict(b) for b in bars]` 副本，返回的是带 MACD 的新 bars
- 最小改动，不影响 `_calc_macd` 的内部逻辑
- 替代方案：让 `_calc_macd` 原地修改 bars，但需要改函数签名

### 3. ADX Wilder 平滑：公式修正 vs 替换实现

**问题**：T0 的 `indicators.py` 中 `smooth - smooth/n + raw` 应为 `(smooth*(n-1) + raw)/n`。

**决策**：修正公式为标准 Wilder 平滑。

**理由**：
- 公式修正最小化改动
- 与 `momentum_core.py` 中已正确的 Wilder 实现保持一致
- 替代方案：统一用一个 Wilder 平滑函数，但需要重构两个文件

### 4. Wyckoff Spring 阈值：调整常量 vs 重写逻辑

**问题**：`WYCKOFF_SPRING_RECLAIM_RATIO = 0.92`（支撑下方 8%）太深。

**决策**：改为 `0.97`（支撑下方 3%），同时增加收盘价需回到支撑上方的检查。

**理由**：
- 3% 是经典 Wyckoff Spring 的典型深度
- 与 Upthrust 的 2% 阈值对称
- 替代方案：动态阈值（基于 ATR），但增加复杂度

### 5. Fusion 权重条件：修正阈值 vs 重构条件

**问题**：`mom_score >= 65`（健康上涨）触发超买权重分配。

**决策**：将阈值提高到 `>= 80`，并要求同时满足 `pos_pct >= 0.7`。

**理由**：
- 80 分是强动量，配合高位位置才构成超买条件
- 最小改动，不影响其他条件分支
- 替代方案：用 RSI 超买代替动量分数，但需要额外数据

### 6. 缠论买点：修正范围 vs 重写算法

**问题**：二买用全局最高价、一买只比两根 MACD 柱。

**决策**：二买改为用局部上涨笔高点；一买暂不改为面积比较（复杂度过高）。

**理由**：
- 二买修复是局部改动，只需找到两个下跌笔之间的上涨笔
- 一买改为面积比较需要重写整个背驰检测逻辑，风险过高
- 替代方案：两个都重写，但超出本次修复范围

## Risks / Trade-offs

**风险 1**：HMM 标签修复会改变所有下游模块的行为
→ 缓解：这是修复正确性，不是改变行为。旧的行为本身就是错的。

**风险 2**：Wyckoff Spring 阈值从 8% 改为 3% 会增加触发频率
→ 缓解：旧阈值几乎不触发，新阈值更接近真实 Spring。配合收盘价检查过滤假信号。

**风险 3**：ADX 公式修复会改变 T0 的趋势强度判定
→ 缓解：旧判定完全失真，新判定是正确的。T0 用户需要重新适应。

**风险 4**：一买暂不改为面积比较，仍然可能有假信号
→ 缓解：当前的两柱比较在大多数场景下能工作，面积比较是优化而非修复。
