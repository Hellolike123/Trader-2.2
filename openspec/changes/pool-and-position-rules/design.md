## Context

基于 2026-05-30 讨论结果，四阶段定位模型（stage_positioning.py）已实现，但仓位管理、选股池规则和入池流程尚未与四阶段挂钩。利弗莫尔框架已被四阶段取代但代码仍在。

## Goals / Non-Goals

**Goals:**
- 清理利弗莫尔死代码
- 仓位跟着大阶段走
- 选股池显示阶段信息
- 入池规则与四阶段挂钩
- 入池流程简化为一步

**Non-Goals:**
- 不改变 trader_shared 核心计算模块
- 不实现 funda skill
- 不实现板块共振

## Decisions

### 1. 仓位管理规则

四阶段 + 硬规则：
- 蓄势期：0-30%（第一笔10%→确认加到20%→突破转主升）
- 主升期：50-80%（突破40%→回踩60%→走强80%）
- 派发期：0-30%（滞涨40%→顶背离20%→跌破清仓）
- 衰退期：0%
- 硬规则：持仓亏损时禁止加仓

### 2. 选股池精简

6 种命令 → 3 种：
- `list` = show + list（池子概览）
- `plan` = rank + plan（作战表，按阶段排序）
- `add` / `remove` 不变

### 3. 入池规则

三关：
1. 阶段筛选：衰退期直接拒绝
2. 评分门槛：蓄势≥70观察/≥80执行，主升≥60执行，派发≥70观察
3. 风控检查：现价跌破止损→拒绝

### 4. 入池流程

原来两步（分析→add）改为一步（分析→回复1→自动入池）。

## Risks / Trade-offs

**[入池拒绝率提高]** 衰退期直接拒绝，可能减少入池数量
→ 这是预期行为，衰退期不应建仓

**[一步入池缺少确认]** 用户回复 1 直接入池
→ 入池前仍需阶段+评分检查，不达标会拒绝
