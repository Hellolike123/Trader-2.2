## Context

仓位轮动当前只看技术指标（高位钝化/确认突破），需要加入四阶段判定。

## Goals / Non-Goals

**Goals:**
- 轮动跟着阶段走
- 技术指标作为辅助判断轮多少
- 输出格式改造

**Non-Goals:**
- 不改变持仓数据格式
- 不改变 signals.jsonl 契约

## Decisions

### 1. 轮动决策逻辑

```
A 票阶段 × B 票阶段 → 决策

主升期 × 任何 → 不轮（让利润跑）
派发期 × 蓄势/主升 → 看技术指标轮动
衰退期 × 任何 → 必须轮（止损/清仓）
蓄势期 × 蓄势期 → 看技术指标
```

### 2. 轮动比例

- 风控退出（衰退期跌破止损）→ 清仓
- 强轮动（派发期+候选确认）→ 轮 1/3
- 轻轮动（派发期+候选接近确认）→ 轮 1/6
- 标准轮动（蓄势期高位钝化+候选确认）→ 轮 25%

### 3. 输出格式

不轮动时：显示分析+持仓+关键价位+触发条件
轮动时：显示分析+持仓+轮动方案+关键价位+触发条件

## Risks / Trade-offs

**[主升期不轮动]** 可能错过最佳轮动时机
→ 这是预期行为，主升期让利润跑
