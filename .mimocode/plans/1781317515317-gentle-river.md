`02-共享模块-shared/trader_shared/account_risk_fuse.py`

### 设计
```python
class AccountRiskFuse:
    """账户级风控熔断器"""

    def check(self, daily_pnl_pct: float, weekly_pnl_pct: float, max_drawdown_pct: float) -> dict:
        """
        Returns:
            {
                "fuse_triggered": bool,
                "fuse_level": "none" | "daily_stop" | "weekly_half" | "full_stop",
                "message": str,  # 人类可读原因
                "action": str,   # "允许交易" | "当天停手" | "下周减半" | "全面停手"
            }
        """
```

### 规则
- 单日亏损 ≥ 1.5% → 当天强制停手
- 单周亏损 ≥ 3% → 下周仓位减半
- 最大回撤 ≥ 15% → 全面降仓/停手
- 读取 `~/.trader/account_state.json` 获取当日/当周已实现盈亏
- 写入 `~/.trader/account_state.json`

### 调用点
- `decision_core.py` 的 `status_layers()` 入口处调用，fuse 触发时 `base_status` 和 `theory_status` 直接覆盖为 "风险回避"
- `run_analysis.py` 输出中追加熔断提示

### 配置
在 `config.py` 中新增：
```python
ACCOUNT_DAILY_LOSS_LIMIT: float = 0.015    # 单日亏损停手阈值
ACCOUNT_WEEKLY_LOSS_LIMIT: float = 0.03    # 单周减半阈值
ACCOUNT_MAX_DRAWDOWN: float = 0.15         # 最大回撤停手阈值
```

## 改动 2：板块共振检查（P1）

### 新建文件
`02-共享模块-shared/trader_shared/resonance.py`

### 设计（V1：两级共振）
```python
def check_resonance(
    market_env: str,       # 大盘环境：牛市/震荡市/熊市
    major_stage: str,      # 个股大阶段：蓄势/主升/派发/衰退
    momentum: str,         # 短期动能：走强/修复/震荡/转弱
) -> dict:
    """
    两级共振评分（V1）：
    - 大盘级别（market_env）
    - 个股级别（major_stage + momentum）

    共振规则：
    - 牛市 + 主升 + 走强 → 强共振（100分）
    - 牛市 + 主升 + 修复 → 中共振（70分）
    - 震荡市 + 蓄势 + 走强 → 中共振（60分）
    - 熊市 + 衰退 + 转弱 → 无共振（0分）
    - 其他组合按对齐程度评分

    Returns:
        {
            "resonance_score": int,  # 0-100
            "resonance_level": "强共振" | "弱共振" | "无共振",
            "market_aligned": bool,
            "stock_aligned": bool,
            "detail": str,
        }
    """
```

### 数据源（V1：粗粒度）
- **不做板块指数**，先用大盘+个股两级共振
- 大盘级：已有 `market_env`（牛市/震荡市/熊市）
- 个股级：已有 `stage_positioning` 的 `major_stage` + `momentum`
- 后续 V2 再扩展板块级（用 AkShare 板块指数或个股涨跌比）

### 调用点
- `stage_positioning.py` 的 `assess_stage()` 中，作为第五层交叉验证
- `run_analysis.py` 输出中追加共振等级提示
- V2 可扩展为三级（加板块级），接口不变

## 改动 3：筹码归编完成度（P2）

### 修改文件
`02-共享模块-shared/trader_shared/chip_distribution.py`

### 设计
在现有 `chip_distribution()` 返回值中新增：
```python
{
    ...existing fields...,
    "redistribution_score": int,  # 0-100, 归编完成度
    "redistribution_note": str,   # "多峰分散" | "归编中" | "单峰集中"
}
```

### 归编评分算法
- 筹码峰数量（1峰=100分，2峰=60分，3+峰=20分）→ 权重40%
- 筹码集中度趋势（concentration_trend 上升→加分）→ 权重30%
- 近5日量比（缩量→加分，说明浮筹清洗中）→ 权重20%
- 波动率收窄（ATR下降→加分）→ 权重10%

### 调用点
- 输出模板中 🔍 主力筹码 段落追加归编状态
