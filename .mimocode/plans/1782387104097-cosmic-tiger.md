# 衰退期止盈逻辑修改方案

## 当前逻辑

```python
elif major_stage == '衰退':
    take = round(current * 1.03, 2)
```

## 修改为

```python
elif major_stage == '衰退':
    take = None  # 衰退期不设止盈，只靠止损退出
```

## 安全网也需要调整

```python
# 安全网: 止盈不能低于现价（衰退期除外）
if take is not None:
    take = max(take, current)
```
