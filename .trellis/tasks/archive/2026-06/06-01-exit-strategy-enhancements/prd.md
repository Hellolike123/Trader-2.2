### 二、已有持仓模式

**问题**：用户经常是已经买了才来查询，系统现在假设从头开始。

**数据来源**：
1. signals.jsonl 有买入记录 → 自动推断成本
2. 用户手动输入 `--cost 60.00` → 使用用户输入
3. 都没有 → 按空仓处理

**评估逻辑**：

| 赚亏 | 阶段 | 建议 |
|------|------|------|
| 赚钱 | 主升期 | 拿着，止盈计划从现在开始 |
| 赚钱 | 派发期 | 减仓，锁定利润 |
| 亏钱 | 蓄势期 | 持有，等反弹到成本价减仓 |
| 亏钱 | 衰退期 | 止损，认亏走人 |
| 赚钱 | 蓄势期 | 部分止盈，留底仓等突破 |
| 亏钱 | 主升期 | 持有，主升期大概率会回来 |

**输出示例**：
```
🎯 今日行动（已有持仓）
  你的成本：60.00
  现价：58.50（亏 2.5%）
  阶段：蓄势期 + 转弱
  
  建议：持有，不加仓
  
  如果反弹到 60.00（成本价）→ 减仓 50%，保本走人
  如果跌破 57.61（支撑位）→ 止损，认亏走人
  如果站稳 59.22（确认位）→ 继续持有，等突破
```

### 三、买点逻辑简化（必要条件 + 加分条件）

**问题**：条件太复杂抓不到买点。5 个条件全满足才买 → 一年可能只触发 1-2 次。

**解决方案**：分"必要条件"和"加分条件"

**初始买点**（简单）：
- 条件：价格到支撑位 → 买 10%
- 只有 1 个条件

**加仓买点**：
- 必要条件（必须满足）：价格突破阻力位并站稳
- 加分条件（满足越多仓位越大）：
  1. 缩量回踩（量比 < 0.8）
  2. RSI 偏低（RSI < 50）
  3. MACD 金叉或柱状线转正
  4. 价格在 EXPMA(10) 上
  5. 威科夫 LPS 确认
- 仓位规则：
  - 必要条件 + 3/5 加分 → 加 10%
  - 必要条件 + 5/5 加分 → 加 15%
  - 必要条件 + 0/5 加分 → 不加

**退出再买**：
- 必要条件：价格回到支撑位 + 支撑位没破
- 加分条件：缩量止跌 / 价格站上 EXPMA(10) / RSI 回升 / 阶段没变坏
- 必要条件 + 2/4 加分 → 买回 10%
- 必要条件 + 0/4 加分 → 不买

### 四、状态机防冲突机制

新增 3 个冲突的解决方案：

| 冲突 | 解决 |
|------|------|
| 越加仓成本越高，最后一跌全亏光 | 加仓部分设独立止损（窄），底仓止损上移（宽） |
| 不知道该止盈还是该加仓 | 阻力位由客观量价表现决定：弱→止盈，强→等回踩加仓 |
| 卖了又涨回去，踏空了 | 退出再买需要满足条件，不是退出了就立刻买回来 |

### 五、威科夫指标共振

**问题**：威科夫信号（BC/UTAD）是概念不是精准指标，需要其他指标确认。

**共振逻辑**：

BC（购买高潮）确认指标：
- RSI > 70（超买）
- MACD 顶背离
- 量比 > 2.0（天量）
- 涨幅 < 1%（滞涨）
- 价格跌破 EXPMA(10)（趋势转弱）
- 3/5 确认 = 信号可信

UTAD（上冲回落）确认指标：
- 价格突破后跌回
- 量比 > 1.5（放量）
- 价格跌回 EXPMA(10) 下方
- 3/3 确认 = 信号可信

### 六、EXPMA 参数

**用途 1：移动止损**（替代 MA20，反应更快）
- 蓄势期：不用 EXPMA（震荡会被反复触发），用支撑位 - 1.5×ATR
- 主升期：EXPMA(10) 做动态支撑
- 派发期：EXPMA(20) 做止损

**用途 2：趋势确认**
- EXPMA(12) 金叉 EXPMA(50) → 趋势转强
- EXPMA(12) 死叉 EXPMA(50) → 趋势转弱

**用途 3：威科夫共振**
- 价格跌破 EXPMA(10) → 确认趋势转弱
- 价格跌回 EXPMA(10) 下方 → 确认假突破

**数据支持**：系统已有 `_ema()` 函数（`momentum_core.py`），不需要新数据源。

### 七、加仓独立止损

**问题**：加仓后假突破，底仓也被拖下水。

**解决**：
- 底仓止损：上移到阻力位（59.05）
- 加仓止损：独立设在回踩支撑位下方（58.50）
- 最坏结果：加仓部分微亏出局，底仓止损在 59.05，整体不亏
