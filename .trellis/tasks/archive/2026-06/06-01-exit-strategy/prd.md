# 退出策略系统 — 从报表到策略

## Goal

将现有"报表系统"升级为"策略系统"：不光告诉用户"是什么"，还要告诉用户"该干嘛"。核心转变：从"数据展示"到"行动指令"。

## 核心设计理念：从数据到行动

```
现在的输出（报表系统）：
  支撑位：57.61
  阻力位：59.05
  止损：56.17
  → 用户："所以呢？"

升级后的输出（策略系统）：
  🎯 今日行动
    动作：不买
    理由：蓄势期动能转弱
    如果买：57.61 不破买 5%，止损 56.17
    关注：明天站稳 59.29 可加仓
  → 用户："明白了，就这么做"
```

## 理论基础

### 止损理论依据
1. **亏损不对称（数学）**：亏 50% 需要涨 100% 才能回本
2. **凯利公式（概率论）**：控制单次亏损，让期望值为正
3. **趋势破位（技术分析）**：跌破支撑 = 市场共识变了
4. **处置效应（行为金融学）**：止损用纪律克服人性

### 止盈理论依据
1. **均值回归（统计学）**：涨多了会跌回来，阻力位是参考点
2. **盈亏比管理（期望值）**：分批卖，保本+锁利
3. **浮盈不是真钱（心理学）**：止盈把"纸上富贵"变成"真金白银"

### 盈亏比
```
盈亏比 = 可能赚的钱 ÷ 可能亏的钱

示例：
  买入 57.61，止盈 62.85（+9.1%），止损 56.17（-2.5%）
  盈亏比 = 9.1% ÷ 2.5% = 3.6 : 1

即使胜率只有 50%，长期也能赚钱
```

## 一、退出策略 = 止盈计划 + 止损计划（两套独立系统）

```
止盈系统（什么时候拿利润）：
  涨到阻力位 → 条件止盈（看威科夫信号）
  涨到 1R 目标 → 卖 1/3
  突破阻力位 → 跟进（新目标、新止损）
  阶段转派发 → 清仓

止损系统（什么时候认亏）：
  跌破支撑位 → 减仓
  移动止损触发 → 减仓
  阶段转衰退 → 清仓
  时间止损 → 走人

两个系统买之前同时定好，买之后各自运行
```

## 总控框架：状态机（买→加→止盈→退出 一体化闭环）

```
整个交易系统只回答三个问题：在哪里买？在哪里加？怎么安全退？

 ❶ 初始建仓 ───────> ❷ 突破跟进/回踩加仓
        │                         │
        ├── 触发初始止损（认错）   ├── 触发加仓止损（保本）
        │                         │
        └───────────────> ❸ 分批止盈 / ❹ 阶段清仓
```

### 状态 1：初始建仓

```
触发条件：价格回踩关键支撑位（威科夫蓄势尾声）
执行动作：初始开仓 10% 仓位
风控绑定：初始止损 = 支撑位 - 1.5×ATR
状态：等待（底仓严禁任何卖出动作）
```

### 状态 2：阻力位分歧判定

```
触发条件：价格首次触及阻力位
判定分支：
  IF 弱（放量滞涨/BC 信号/顶分型）→ 执行止盈：卖 1/3，不启动加仓
  IF 强（大阳线放量突破）→ 执行持股：底仓不动，激活加仓监控
```

### 状态 3：回踩加仓与止损联动

```
加仓买点：价格突破阻力位后回踩该位置，缩量止跌（威科夫 LPS 确认）
加仓动作：追加 10% 仓位

防冲突风控联动（核心）：
  1. 加仓部分独立止损：设在回踩支撑位下方（比如 58.50）
     → 假突破回踩，加仓部分微亏出局
  2. 底仓止损上移：加仓成功后，底仓止损自动上移到阻力位（59.05）
     → 整体头寸保本
  3. 最坏结果：加仓部分亏一点，底仓止损在 59.05，整体不亏
     → 不会"因为加仓把赚钱的单子做成亏损"
```

### 状态 4：主升浪跟踪与阶段清仓

```
跟踪状态：
  筹码没搬家 + 价格在 EXPMA(10) 上 → 全仓拿着
  
终极清仓触发：
  高位出现 BC（购买高潮）→ 全仓清仓
  高位出现 UTAD（上冲回落）→ 全仓清仓
  底部筹码搬家 > 50% → 全仓清仓
  价格放量跌破高位震荡区下沿 → 全仓清仓
  → 包括底仓和加仓，一并清仓，整个交易生命周期结束
```

### 状态机防冲突机制

```
冲突 1："越加仓成本越高，最后一跌全亏光"
解决：加仓部分设独立止损（窄），底仓止损上移（宽）
  加仓失败 → 只亏皮毛
  加仓成功 → 利润翻倍

冲突 2："不知道该止盈还是该加仓"
解决：阻力位不是一刀切，由客观量价表现决定
  弱 → 触发止盈
  强 → 等待回踩加仓
  一切由条件触发，不靠主观判断
```

## 二、分批止盈（条件止盈，不是机械止盈）

### 2.1 原策略问题

```
原策略：到了阻力位就卖
问题：
  - 突破了阻力位也卖 → 卖飞
  - 假突破也卖 → 卖对了
  - 无法区分真假突破
```

### 2.2 升级策略：威科夫信号驱动止盈

```
价格触及阻力位 → 不急着卖，看信号：

条件 A（不卖）：
  大阳线突破 + 放量 → 继续持有
  说明：市场共识变了，阻力位可能被突破

条件 B（卖 1/3）：
  出现购买高潮（BC）→ 卖 1/3
  BC 定义：天量 + 滞涨 + 高位放量阴线
  量化：量比 > 2.0 且 涨幅 < 1% 且 出现上影线 > 2%

条件 C（立刻减仓）：
  出现 UTAD（上冲回落）→ 立刻减仓
  UTAD 定义：突破阻力位后收盘跌回
  量化：最高价 > 阻力×1.02 且 收盘价 < 阻力×0.995
  代码已有：wyckoff_core.py:_detect_upthrust()
```

### 2.3 三批退出计划

| 批次 | 触发条件 | 动作 | 原因 |
|------|----------|------|------|
| 第一笔 | BC 信号出现 | 卖 1/3 | 购买高潮，主力在出货 |
| 第二笔 | 1R 目标达到 | 卖 1/3 | 保本，锁定部分利润 |
| 第三笔 | 阶段转派发 或 筹码搬家 > 50% | 清仓 | 趋势变了 |

### 2.4 突破跟进逻辑

```
价格突破阻力位并站稳：
  1. 止损上移：旧阻力位 → 新支撑位
  2. 新止盈目标：下一个阻力位
  3. 剩余仓位继续持有
  4. 回踩新支撑不破 → 可以加仓

价格突破后又跌回来（假突破）：
  1. 假突破确认（UTAD 信号）
  2. 立刻减仓
  3. 止损下移回原支撑位
```

## 三、三层止损（止损放宽 + 仓位调整）

### 3.1 止损放宽（牛市防洗盘）

```
原策略：止损 = 支撑位 - 2.5%
问题：牛市波动大，容易被洗出去

新策略：止损 = 支撑位 - 1.5×ATR
  ATR = 3.69
  止损 = 57.61 - 1.5×3.69 = 52.07
  止损空间：从 2.5% 放宽到 9.6%

仓位自动调整：
  为了保持同样的亏损金额（比如亏 1000 元）：
  原仓位：1000 ÷ (57.61×2.5%) = 694 股
  新仓位：1000 ÷ (57.61×9.6%) = 181 股
  
  止损放宽了，但仓位也降了，总风险不变
```

### 3.2 移动止损（筹码驱动 + EXPMA）

```
原策略：最高价 × 0.82（回撤 18%）
问题：固定比例不考虑筹码分布和趋势变化

新策略：筹码驱动 + EXPMA 动态止损

  底部筹码峰没松动：
    主升期 → 止损跟 EXPMA(10) 走（动态支撑）
    蓄势期 → 止损跟 EXPMA(20) 走（趋势参考）
  
  底部筹码峰松动 > 40%：
    止损收紧到 EXPMA(20)
  
  底部筹码峰搬家 > 50%：
    清仓

为什么用 EXPMA 而不是 MA？
  EXPMA 对最近价格权重更高，反应更快
  价格跌了 MA20 还在高位，EXPMA(20) 已经反应
  效果：止损更及时，少亏一点

EXPMA 参数：
  EXPMA(10) → 主升期动态支撑（贴合价格）
  EXPMA(20) → 移动止损参考（趋势线）
  EXPMA(50) → 趋势确认（金叉/死叉）

数据支持：
  系统已有 _ema() 函数（momentum_core.py）
  数据源已有日线 close 数据
  不需要额外数据
```

### 3.3 阶段止损

| 阶段 | 止损位 | 原因 |
|------|--------|------|
| 蓄势期 | 支撑位 - 1.5×ATR | 保护本金 |
| 主升期 | EXPMA(20) | 保护利润（比 MA20 更灵敏） |
| 派发期 | EXPMA(20) 上方 | 锁定收益 |
| 衰退期 | 不持有 | — |

### 3.4 时间止损

| 阶段 | 期限 | 动作 |
|------|------|------|
| 蓄势期买入 | 30 天不突破 | 走人 |
| 主升期买入 | 15 天不创新高 | 减仓 |
