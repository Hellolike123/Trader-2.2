# 退出策略 — 已发现 Bug 清单

## Bug 1：突破确认信号误触发
- **位置**：`run_analysis.py:1392`
- **问题**：`current >= confirm * 0.98` 容差太松，差 2% 就触发突破确认
- **示例**：确认位 59.22，现价 58.50，58.50 >= 58.04 就触发了（错误）
- **正确逻辑**：`current >= confirm`（价格真正站稳才触发）
- **优先级**：🔴 高

## Bug 2：空仓显示止盈计划
- **位置**：`run_analysis.py` 止盈计划输出逻辑
- **问题**：空仓状态也显示止盈计划（"买了之后怎么卖"）
- **正确逻辑**：止盈计划只在有持仓时显示
- **优先级**：🔴 高

## Bug 3：止盈计划第1笔没有价格
- **位置**：`run_analysis.py` 止盈计划生成逻辑
- **问题**：第1笔只写"等待 BC 信号"，没有具体价格
- **正确逻辑**：第1笔应该有价格（阻力位或 1R 目标）
- **优先级**：🟡 中

## Bug 4：🎯 今日行动条件矛盾
- **位置**：`run_analysis.py` 今日行动输出逻辑
- **问题**：说"不买"，但价格在买入区间内（57.61-58.76）
- **正确逻辑**：价格在买入区间内时，应该说"可以试探买"而不是"不买"
- **优先级**：🟡 中
