## 1. 产品裁决 / CLI 行为

### 1.1 CLI 三档

1. `python3 scripts/final_wyckoff.py --target <NAME>`  
   默认输出 **B 卡**，本文为唯一骨架合同。
2. `python3 scripts/final_wyckoff.py --target <NAME> --full`  
   输出旧完整详析，沿用现 `render_wyckoff_detail` 的完整骨架；`wyckoff-skill-deep-card-handoff.md` 改为 `--full` 合同。
3. `python3 scripts/final_wyckoff.py --target <NAME> --brief`  
   仍输出最短卡，沿用现 `render_wyckoff_card`。

优先级：`--brief` 与 `--full` 不应同时使用；如实现层需要兜底，CLI 应报参数冲突，不默默选一档。

### 1.2 做

1. 默认 `--target` 改为「周线大阶段定方向 + 日线本波做波段」B 卡。
2. 标题行只写：`{名}（{码}）｜现价 {price}`；默认 B 卡禁止前缀 `威科夫 —` 或 `威科夫详析 —`。
3. 标题下固定三行总览：`周线：...`、`日线本波：...`、`入池：...`。
4. `🧭 周线 · 大阶段` 用周线主侧定方向，输出一句话 + 满灯竖排。
5. `⚡ 日线 · 本波` 跟本波事件走，输出一句话 + 吸筹满灯竖排；不得用失败 Phase A 的 bias 把本波笼统写成「日偏空」。
6. 中文释义主要落在灯行 `CODE（中文）`；正文少嵌套括号。
7. `🔮 推演` 固定保留，按现在 / 若变好 / 若变坏 / ⭐ 盯分行缩进，段内先周后日；「现在」段内附周/日量度行（仅 L3 出目标价）。
8. `🔔 变化` 默认折叠：无新亮 / 熄灭时整块省略；有变化时保留一行短句。
9. 保留 L0-L3 门禁表达：L1 才能写雏形，L2/L3 才能写箱体，量度仅 L3；未达 L3 写「未达 L3，暂不测算」，禁止假目标。
10. 同步输出文档、快路径文档、本文与测试。

### 1.3 不做

1. 不改 SC / AR / ST / LPS / SOS 等检测阈值。
2. 不改 `phase_a_status`、`tr_maturity`、`box_display_mode` 的计算语义。
3. 不改 fusion、decision_view、trader 出手、池分道、mistery_gate。
4. 不在 render 层补事件、补假箱体、补假量度。
5. 不把旧完整详析删除；只迁移为 `--full`。
6. 不把灯改成横排；禁止 `● SC｜● AR` 这种横排灯。
7. 不使用幕类隐喻叙事；只用周线大阶段 / 日线本波直述。
8. 周线 ARE 无 BC 时，不得把下一空心灯接到吸筹 SC；写派发未确认 / 观望。

## 3. 块级规则

### 3.1 标题与总览三行

格式：

```text
{名}（{码}）｜现价 {price}
周线：{偏多|偏空|中性}｜{大阶段短句}｜{可盯小波段|慎做|先别做}
日线本波：{本波短句}
入池：{短判断}
```

规则：

1. 标题行必须同一行包含名称、代码、现价；默认 B 卡不得输出 `威科夫 —`、`威科夫详析 —` 或 `日+周`。
2. `周线：` 只读周线主侧与大阶段；它回答方向背景，不替日线给交易触发。
3. 周线第三槽仅三档：`可盯小波段` / `慎做` / `先别做`；不得写买卖、仓位、低吸、可执行。
4. `日线本波：` 只写本波事实短句。failed 后若有 SOS，写 `Phase A 失效 · 破后强势｜本波 SOS 强`；若无新强势，写 `Phase A 失效｜须重新寻底`；若仅 LPS，写 `Phase A 失效｜本波 LPS 修复`。
5. `入池：` 只给结构入池短判断：`建议入池` / `暂不建议入池（短因）` / `结构偏空，暂不建议入池`。
6. 周线总览第二槽：L1 有批准上下沿时必须写出 `雏形 {lo}～{hi}（待 ST）`（参考用，非成熟箱）；不得只写「雏形待 ST」却藏价。
7. 日线 failed 块：禁止健康「雏形/箱体」；可写 `旧SC {价}（仅对照）`，供对照，不复活旧结构。

### 3.2 周线 · 大阶段

一句话拼法：

```text
{周线主侧语气}｜{大阶段/主事件}｜{区间成熟度/门禁}
```

硬要求：

1. 周线是方向背景：用周线 `bias` / `phase` / `active_events` / `tr_maturity` / `box_display_mode` 等字段拼短句。
2. 根据周线主侧选择一条满灯链：
   - 吸筹链：SC / AR / ST / LPS / SOS。
   - 派发链：BC / ARE / SOW / LPSY / UTAD。
3. 同一张默认 B 卡中，周线灯不混用吸筹链与派发链；若主侧不明确，按当前 view 主事件和 bias 选择最保守一侧，并在一句话写 `中性` / `观望`。
4. 区间表达遵守 L0-L3：
   - L0 / `box_display_mode=none`：不得展示分位上下沿为箱体或雏形；failed 可写 `旧SC {价}（仅对照）`。
   - L1：必须尽量写出 `雏形 {lower}～{upper}（待 ST）`（总览与大阶段均可见价）。
   - L2 / L3：可写 `箱体 {lower}～{upper}`。
   - 未达 L3：写 `未达 L3`；不得给量度目标。
5. 周线 ARE 无 BC：写 `派发未确认` / `中线观望`，满灯用派发链，下一空心灯不得接吸筹 SC。

### 3.3 日线 · 本波

一句话拼法：

```text
{本波主事件/强弱事实}｜{failed/旧底状态}｜{区间成熟度/门禁}
```

硬要求：

1. 日线本波只给人读波段结构，不进中线定论，不进 fusion，不单独开仓。
2. `phase_a_status == "failed"` 或 `phase_a_range.status == "failed"` 时，必须写 `Phase A 失效` 失败语义（禁 `旧底已废` / 英文 `failed`）。
3. failed 且无新强势事件：本波短句写 `Phase A 失效｜须重新寻底`，灯中 SC 可亮，但不得写 `还差 AR` / `链可推进`。
4. failed 且有 SOS：本波短句写 `Phase A 失效 · 破后强势｜本波 SOS 强`；允许 `● SC` 与 `● SOS` 同在；必须说明灯是事实并列，不按顺序推进读。
5. failed 且有 LPS、无 SOS：写 `Phase A 失效｜本波 LPS 修复`，不得写成旧吸筹链恢复健康。
6. 日线灯固定吸筹满灯竖排：SC / AR / ST / LPS / SOS；不得横排，不得只列已亮 + 下一盯。

### 3.4 `🔔 变化`

默认折叠：

1. 无新亮、无熄灭：整块省略。
2. 仅仍亮：整块省略。
3. 有新亮或熄灭：出现一行短句。

格式示例：

```text
🔔 变化
  新亮：周 AR（自动反弹）；熄灭：日 ST（二次测试）
```

禁止恢复旧详析里的“首次记录，暂无对比”默认块，除非 `--full`。

### 3.5 `🔮 推演` + `⭐ 盯`

短推演块必须出现在默认 B 卡。

规则：

1. 固定四段：`现在` / `若变好` / `若变坏` / `⭐ 盯`。
2. 标签单独一行；正文缩进；段间空行。
3. 每段正文先写 `周线：...`，再写 `日线：...`。
4. 失败态日线「若变好」写重新寻底 / 新 SC，或 failed+SOS 的回踩站稳；不得写「若出现 AR…链可推进」或「还差」。
5. 「若变坏」可引用周线批准下沿（L1+），L0 不得拿分位沿冒充。
6. `⭐ 盯` 段末固定：`本卡不下单；出手/分道看 trader`；不写底部重复入池长文。
7. 「现在」段在日线行后固定两行量度（先周后日），走 `format_cause_effect_display` / `measure_allowed`：
   - `周线量度：…` / `日线量度：…`
   - `measure_allowed` 或 `tr_maturity=L3` 且有上下目标 → `量度目标：上 x｜下 y（P&F，非出手）`（或高度1:1 标签）
   - 否则 → `未达 L3，暂不测算`（或数据不足时 `数据不足，暂不测算`）
   - **禁止**未达 L3 时贴残留 `cause_effect_*` 数字；量度不是出手指令。

## 4. 灯规则（默认 B 卡）

### 4.1 满灯竖排硬规则

1. 灯必须竖排，一行一灯。
2. 禁止横排灯：`● SC｜● AR`、`● SC / ● AR`、`SC、AR 已亮` 均不合格。
3. 缩写必须带中文括号：`SC（卖力高潮）`、`AR（自动反弹）`、`ST（二次测试）`。
4. 亮灯格式：`● CODE（中文）{价?}`。
5. 空心灯格式：`○ CODE（中文）`；不写 `未亮` 长尾。
6. 默认 B 卡是满灯卡：不得只列已亮灯 + 至多一个下一盯。

### 4.2 周线满灯链

按周线主侧二选一：

```text
吸筹链：
{●|○} SC（卖力高潮）{price?}
{●|○} AR（自动反弹）{price?}
{●|○} ST（二次测试）{price?}
{●|○} LPS（最后支撑点）{price?}
{●|○} SOS（强势信号）{price?}

派发链：
{●|○} BC（买力高潮）{price?}
{●|○} ARE（自动回落）{price?}
{●|○} SOW（弱势信号）{price?}
{●|○} LPSY（最后供应点）{price?}
{●|○} UTAD（派发后上冲）{price?}
```

规则：

1. 只能选一条主链；不要吸筹 / 派发同块混排。
2. 亮灯价格只来自引擎事件价或 view 中批准价格源；没有价格就省略价格。
3. 不得为了满灯而手工点亮或手工定价。
4. ARE 无 BC 时，派发链可出现 `○ BC` + `● ARE`；一句话必须说明 `派发未确认`。

### 4.3 日线本波满灯链

日线固定吸筹链：

```text
{●|○} SC（卖力高潮）{price?}
{●|○} AR（自动反弹）{price?}
{●|○} ST（二次测试）{price?}
{●|○} LPS（最后支撑点）{price?}
{●|○} SOS（强势信号）{price?}
```

failed 规则：

1. 失败态不灭已亮灯。旧 SC 已亮仍可显示 `● SC（卖力高潮）{价}`。
2. failed 后无新强势：`● SC` 后可继续显示空心 AR/ST/LPS/SOS，但正文必须写 `Phase A 失效｜须重新寻底`，不得把空心 AR 当下一步健康推进。
3. failed+SOS：允许 `● SC` 与 `● SOS` 同在；必须加说明，避免读成顺序点亮链。
4. 禁止：

```text
威：SC，还差 AR
若出现 AR，链可推进
○ AR（自动反弹）下一盯
日偏空
```
