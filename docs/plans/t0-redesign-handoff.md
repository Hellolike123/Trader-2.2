## 0. 背景与核验

### 现有 T0 的问题（核验后）

1. **基调纯看日内箱位，不看日线方向**【已核验】
   - `t0_core.py:530-541` `_scenario_verb`：`_box_zone_bias(plan)` 返回 high→看反T，low→看正T，中轴→观望
   - 即"价格在日内低区就正T，在高区就反T"——**完全不参考日线威科夫阶段**
   - 后果：日线派发的票，日内跌到低区会判"正T（低吸高抛）"——逆日线方向低吸，风险大

2. **盯盘信号三重共振太严，50 天 0 成交**【MEMORY 记载】
   - 三重共振 = Al Brooks + 威科夫 + 动量(RSI 12棒背离)
   - RSI 12棒背离是日线/4小时级信号，塞到 5 分钟级"从不与 ab/wyckoff 同帧"
   - 三重共振是波段确认逻辑，T+0 吃先手，等不起

3. **报告格式本身 OK**【已核验 output-template.md】
   - 标题(VWAP) → 基调 → 点位(低吸/止损/高抛) → 盈亏比 → 风控，是参考卡不是指令
   - 禁止"可执行/三重共振买"指令叙事（合规）
   - **报告格式不用大改，要改的是"基调来源"和"盯盘触发逻辑"**

### 核心判断
现有 T0 是"用日线思维做日内"——三重共振是波段框架，硬塞日内必然 0 成交；基调纯看日内位置不参考日线，可能逆势做T。重设计核心：**日线定方向，日内找点位，单信号即出手。**

## 1. 方向判定：日线定基调（核心改动）

### 现状
`t0_core.py:536` `_box_zone_bias(plan)` —— 纯日内箱位定正T/反T

### 改为
日线威科夫阶段定大方向，日内箱位只做"时机微调"：

| 日线威科夫阶段 | 基调 | 含义 |
|---------------|------|------|
| accumulation_a/b/c/d / markup | 看正T | 日线偏多，低吸高抛 |
| distribution_a/b/c/d / markdown | 看反T | 日线偏空/派发，高抛低吸 |
| none / 无明确阶段 | 按日内箱位 | 中性，近低正T近高反T |

**关键**：日线方向优先于日内箱位。日线派发时，即使日内在低区也不做正T（逆势低吸危险）；日线积累时，即使日内在高区也不做反T。

### 实现锚点
- `t0_core.py:530-541` `_scenario_verb`：改为先读日线 phase（report 已有 `wyckoff`/`midline_stage` 字段），再结合箱位
- 日线 phase 来源：`report["wyckoff"]["phase"]` 或 `build_price_point_model` 已注入的日线背景

### 风险
改变基调判定会改变所有票的 T0 方向。须配语义回归（D4）验证：哪些票基调变了、变得对不对（逆势做T的票是否被纠正）。

## 2. 日内信号：关键位 + 量价，扔掉 RSI 背离

### 现状
三重共振（AB + 威科夫 + 动量RSI 12棒背离），50 天 0 触发

### 改为
日内出手条件（满足任一 + 顺日线方向即可，不要求同时）：

1. **VWAP 回归**：价格偏离均价线 >1.5% + 缩量 → 做回归
2. **前高/前低突破**：放量突破日内前高 + 顺日线方向 → 跟突破；缩量到前高 + 逆日线 → 假突破反向
3. **开盘价失守/收复**：开盘 30 分钟后，站稳开盘价上方(顺多)→低吸；下方(顺空)→高抛
4. **Al Brooks 信号棒**：保留作单一结构信号（不是三重共振之一），出现高质量信号棒 + 顺日线即出手

**扔掉**：RSI 12棒背离（错位信号，日线级塞 5 分钟级）

### 实现锚点
- `t0_core.py` / `t0_price_point_engine.py`：信号生成逻辑
- `build_price_point_model`：三重共振改单信号（保留 AB 为主信号，威科夫/动量降为"背景参考"非共振条件）
- VWAP 已有（report 标题行）；前高前低/开盘价需从日内 bars 提取

### 风险
信号放宽后出手频率上升，可能引入噪声交易。须回测验证：单信号 vs 三重共振的胜率/盈亏比对比。

## 3. 盯盘触发：单信号即提醒

### 现状
`t0_monitor` 等三重共振才推送提醒 → 0 触发

### 改为
- 出现任一单信号（VWAP回归/前高前低突破/开盘价收复/AB信号棒）+ 顺日线方向 → 推送提醒
- 提醒内容：信号类型 + 触价位 + 日线方向 + "人确认"
- **不等三共振**

### 实现锚点
- `t0_monitor.py` `_cached_build_plan`：触发条件
- `t0_run.py`：信号判定

### 预期
一只票一天 1-2 次提醒（不是 0，也不是 5+）。只抓开盘定调/午前/尾盘三时段。

## 4. 选股筛选（前置闸）

### 现状
MEMORY 未记 T0 有选股筛。疑似对所有票跑 T0。

### 改为
T0 前置筛选，不满足的票直接"今日宜不做"：

- **无底仓 → 不做**（T+0 前提是有底仓；无底仓报告写"不做T召唤"）

## 6. 报告怎么用（不改格式，改基调来源）

报告格式（output-template.md）保持不变。交易员用法（写进 ai-guide.md 供参考）：
1. **开盘前**看基调（正T/反T/观望）定方向
2. **挂预警**在低吸/止损/高抛三个价位，不用盯盘
3. **到价后自己看量价**确认出手——报告给"在哪等"，"买不买"是人确认
4. **不等盯盘推送**——盯盘是闹钟，报告是作战地图；闹钟没响按地图走
5. **14:50 平T仓**
