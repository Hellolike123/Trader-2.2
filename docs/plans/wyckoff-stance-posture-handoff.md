## 1. 总览

在标题下增加两行（可与旧周线/日线本波行并存或替换周线 tier 语义）：

```
局：{周线标签} · {日线标签}
姿态：{观望|只盯结构|等确认|可跟踪}｜{局面一句}
```

保留：`周线：` / `日线本波：` / `入池：`（入池算法不变）。

### 周线标签
- 派发未确认（ARE 无 BC）
- 派发中（派发侧）
- 吸筹失效（week failed）
- 吸筹中（吸筹侧有灯）
- 结构未明

### 日线标签
- 本波未成型
- 本波无新SC（failed 无 SOS/LPS）
- 破后强势（failed+SOS）
- 修复中（failed+LPS）
- 链推进中（有吸筹灯且非 failed）
- 结构未明

### 姿态
- 可跟踪：现「建议入池」
- 观望：结构偏空 / 日线未成型或本波无新SC / 双L0 等冷
- 等确认：有链但缺下一灯（非冷）
- 只盯结构：其余

## 4. 推演 → 三行
```
📌 现在 / 变好 / 变差
  现在：{姿态}｜{局面}
  变好：{合成一句，条件只写这里}
  变差：{合成一句}
```
删除：`若变好/若变坏/⭐ 盯` 四段旧骨架；删除量度四行（可并入变好外；本迭代 B 卡去掉量度以减噪，L3 仍可在日/周主句未达 L3 体现）。
**删除**尾句 `本卡不下单；出手/分道看 trader`。

### 变好/变差合成（简规）
- 周线派发 + 日线未成型/无新SC：  
  - 变好：`派发缓和，并且出现本波新SC`  
  - 变差：`派发再加深，或日线无SC继续破位`
- 其它：周线 better/worse 与日线 better/worse 用「；」拼接，去重「补」字（已无）。
