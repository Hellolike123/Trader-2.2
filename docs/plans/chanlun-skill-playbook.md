> **注意**: 缠论有**自己的体系**，不要把威科夫的 SC/箱体/Phase A 小本本照搬过来；复用的是**工作方法**，不是威科夫语义。

## 0. 用户真正关心的四件事（验收主轴）

专项报告与引擎验收必须围着这四条转，缺一条不算过：

| # | 关心点 | 要验什么 | 常见坑 |
|---|--------|----------|--------|
| **1** | **取数对不对** | 日/周/（若用）30m 的 OHLCV 是否同一复权、时序升序、根数够成笔；symbol/市场对；缺数要诚实报不足，禁止静默用错周期数据 | 日线冒充周线；未复权混用；周末缺口未处理；取错标的 |
| **2** | **期限（周期）用得对不对** | 中线结构用哪一级 K、短线用哪一级 K，必须合同写死；禁止短线笔结果写进中线定论；周不足时的 fallback 规则要明示（见 `BUSINESS.md` §2.1） | 日线笔当中线；daily_fallback 未标注；回看根数不够成段却硬讲中枢 |
| **3** | **一买 / 二买 / 三买** | 只展示引擎已判定的买卖点类型与价/笔依据；定义跟法源（一类：中枢+背驰等；二类：反弹不创新高后的回踩；三类：中枢上/下方回踩不破——以 `BUSINESS.md` / `formulas.md` 为准）；**禁止** render 手补买卖点 | 把盘感当二买；三类写成破中枢；有笔无买卖点却编「接近一买」 |
| **4** | **笔向上 / 向下对不对** | 当前笔方向、最近笔序列涨跌是否与高低点分型规则一致；向上笔/向下笔数量与面板「笔数」一致；破坏与延伸跟引擎一致 | 笔方向反了；把线段方向当笔；合并笔后方向未更新仍显示旧向 |

> 用户原话对齐：缠论不见得和威科夫一样；关心取数、期限、一二三买、笔向上向下。

## 1. 从威科夫这轮复用的「方法」（不是复用威科夫概念）

1. **先对话/对照票暴露问题 → 再写 handoff → 再写码**。  
2. **法源优先**：未写进 handoff 的行为禁止发明（尤其出手、fusion）。  
3. **四 Agent**：方案文档 → 写码+测 → 查验 →（PASS 后）独立复审 → PR。  
4. **展示与检测分离**：专项面板只渲染引擎字段；不在 render 里重算笔/买卖点。  
5. **假无 / 假有都要防**：周期/回看不够会假无；破坏了还不更新会假有——缠论用**笔破坏 / 买卖点失效 / 级别错配**自己的语言写清，勿抄 SC 破位文案硬套。  
6. **微信红线**与 `_common/agent-rules.md` 一致；专项卡不下单指令词。

## 3. 正式手递必须写进的合同块（Agent1 开工清单）

新建例如 `docs/plans/chanlun-skill-deep-card-handoff.md`（名可调），**至少**含：

### 3.1 取数合同
- 各周期 `days` / `WEEKLY_LOOKBACK_BARS` / 最小成笔根数  
- 复权口径、升序、失败时面板文案  
- Skill/报告入口与 `load_market_snapshot`（或现行 SSOT）一致

### 3.2 期限合同
- 中线块：默认周 K；不足时是否 `daily_fallback` + 必须标注「（日线）」  
- 短线块：日 K（是否加 30m 仅确认，合同写死）  
- 禁止：短线笔写入中线关键价主路径

### 3.3 买卖点合同
- 一买 / 二买 / 三买（及卖点若展示）字段来源表：`signal` / `price` / `reason` / 关联笔或中枢  
- 未触发：诚实「未形成」类文案，禁止暗示「马上就是一买」  
- 与 `buy_point_lifecycle`（若接）关系：失败 signal_id 不得当新开

### 3.4 笔方向合同
- 面板必须能核对：当前笔方向（上/下）、最近 N 笔方向序列、笔数  
- 与引擎 `strokes` 一致；测例锁「最后一笔向上/向下」

### 3.5 验收表（建议 ID）
| ID | 必须 |
|----|------|
| C-D1 | 取数：错周期/不足有明确失败或标注，不静默 |
| C-D2 | 期限：中线周 / 短线日（及 fallback 规则）面板可区分 |
| C-D3 | 一买二买三买仅引擎字段；禁手补；禁下单词 |
| C-D4 | 笔方向与笔数与引擎一致（合成夹具） |
| C-D5 | 微信红线 + 与 output-template 同源 |
| C-D6 | 相关 pytest 绿；勿改 fusion/威科夫中线定论 |

## 4. 四 Agent 分工（同威科夫这轮）

| 角色 | 职责 |
|------|------|
| **Agent1 方案** | 只写/勘误 handoff；把 §0 四关心点写成不可删验收项 |
| **Agent2 写码** | 只读新手递；引擎只在 `trader_shared`；Skill 入口 shim |
| **Agent3 查验** | 对照手递 + 四关心点逐项 ✅/❌；跑测；抓假买卖点/笔反向 |
| **Agent4 复审** | Agent3 PASS 后再独立全看一遍 |

父 Agent：通过后再 PR；PR 必带法源、对照清单、查验结论、测试结果。

## 5. 硬禁止

- 把威科夫 SC/箱体/Phase A 持久化逻辑**原样抄**进缠论当「期限」解决方案  
- render 手补一买二买三买  
- 用均线或「看起来像」判笔方向  
- 专项卡覆盖威科夫中线阶段或直接给仓位指令  
- 无 handoff 大改
