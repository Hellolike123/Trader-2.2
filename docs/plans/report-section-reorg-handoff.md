## 0. 本迭代范围

### 0.1 做

1. **面板主轴改按主题**：价格状态 → 理论分析 → 支撑阻力 → 出手 → 尾部。  
2. **删除**中线「阶段：」行与「定论：」行（含拼装的「无阶段 · 偏空（…）」）；阶段信息只留在 `威科夫：` 正文。

### 1.1 禁止出现（本迭代）

- 中线块内独立行：`阶段：`、`定论：`  
- 支撑阻力区内：`量度目标` / `P&F` / `下沿…（L3）` 作为威科夫量度  
- 成功路径用日线 `key_levels` 冒充中线支撑阻力价（既有红线不变）  
- Markdown `#` / `**` / `|...|` 表 / `---` / `*/-` 列表符  

### 1.2 Emoji 标题（冻结）

| 区 | 标题行 |
|----|--------|
| 价格状态 | `📊 价格状态` |
| 理论分析 | `📐 理论分析` |
| 支撑阻力 | `🎯 支撑阻力` |
| 出手 | `✅ 出手` |

子块标签用缩进纯文：`中线` / `短线`（不加第二套 emoji 轨标 🧭/⚡，避免双层主轴）。

## 6. 用户已确认的产品裁决（防忘）

1. 主题分区优于中短轨主轴。  
2. 阶段/定论拼盘删除更清晰。  
3. P&F 量度属威科夫栏；支撑阻力是另一套逻辑。  
4. ST 前只雏形、ST 后才箱体、L3 才量度——保持严格闸。  
5. L3 要显式下沿/上沿；量度上/下 ≠ 箱体下沿。  
6. 本迭代先落地展示重组；算法净化（Fib/低吸挂缠论）后续再改。
