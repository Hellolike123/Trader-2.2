## 1. 产品裁决

关闭态（`decision_view` / 纪律否决新开：`allow_new_entry=False`，或动作文案含「不新开/不买/不追/观望」）下，面板**不得**再用「低吸/加仓/持有」等出手动词勾引。  
双轨张力保留：meta 动能走强、短线缠论看涨 vs 先别买——**不**强行同向。

### 1.1 做（对照预览 · 顺丰类关闭票）

| ID | 改什么 | 合同 |
|----|--------|------|
| D-R1 | **定论拧句** | 若 `_bias_tag=偏空`（或 `weekly_frame=破坏` / mid 含「框破坏」「战略减」），且 `midline_verdict_note` 含「双源无明确方向」→ **改写定论为单一句**，不得再叠「无方向 · 偏空」。推荐形：`定论：中线框破坏 · 偏空 · 战略减（周线威科夫无阶段，缠论盘整仅副读）`；无框破坏事实时：`定论：偏空（{短因}）（周线威科夫{阶段短词}，缠论{副读}仅副读）`。有真实方向 note（共振/领先）且与偏空不冲突时，仍可 `note · 偏空（短因）`。 |
| D-R2 | **短线关键价 · 买区** | `allow_new_entry=False` 时：标签 `低吸区` → `计划买区`；注解须含「未放行」语义（可用 `未放行，仅标记` / `等确认`），**禁止**「回踩买」暗示下手。 |
| D-R3 | **短线关键价 · MA5** | 关闭态（同上或动作含不新开）时：`加仓试探` → `观察`。 |
| D-R4 | **短线关键价 · 现价** | `has_position=False` 时：`持有，不追` → `不追`；有仓仍可用持有类措辞。 |
| D-R5 | **T0** | `not has_position` 且关闭态： **一律** `T0：无底仓，不启用（与出手一致，不新开）`；**禁止**再打 `日内 T0：…低吸…高抛`。有仓才可打日内低吸/高抛结构参考。 |
| D-R6 | **中线关键价动词** | 关闭态或定论偏空/框破坏时：回踩区注解禁「分批低吸/才谈低吸」→ `结构参考`（可保留远近距百分比前缀）；黄金买点禁「最佳低吸位」→ 改 `黄金位` 标签或注解改为 `50%回撤` / `结构参考`（勿「最佳低吸」）。压力/目标「分批减仓/止盈」可保留（减仓语义，非新开）。 |
| D-R7 | **风险复读** | 风险行**禁止**再贴与定论相同的「中线偏空（短因）」整段；关闭态风险优先：`现价不宜追` + 止损等，不重复定论偏空句。 |

### 1.2 不做

1. 不改 `synthesize_midline_verdict` 的 bias/stage 算法（可只在 **render** 层改写展示句；若必须动 note 生成，仅允许结论块展示辅助，禁止改阶段词表）。
2. 不改 fusion / resonance / decision_view / chan_discipline 门禁阈值。
3. 不删「新开」与「动作」两行（本次不做二选一）。
4. 不强行统一「综合动能走强」与中线偏空、短线缠论看涨与先别买。
5. 不嵌威科夫/缠论 skill 详卡；不恢复「阶段：」行。
