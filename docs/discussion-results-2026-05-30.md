### 2. 仓位管理规则

四阶段 + 一条硬规则：

蓄势期：0-30%（试探）
  第一笔 10% → 确认站稳支撑 → 加到 20%
  突破确认 → 阶段转主升

主升期：50-80%（重仓）
  突破确认 → 加到 40%
  回踩不破 → 加到 60%
  持续走强 → 最多 80%

派发期：0-30%（减仓）
  高位滞涨 → 减到 40%
  MACD 顶背离 → 减到 20%
  跌破关键位 → 清仓

衰退期：0%（空仓）

硬规则：持仓亏损时，禁止加仓

### 3. 缓存规则

盘中（9:30-15:00）：
  trader 日线K线 → 用缓存
  trader 实时行情 → 抓最新
  t0 实时行情 → 抓最新（不缓存）
  review 日线K线 → 用缓存

盘后/周末：
  所有数据用缓存

自动清理：
  交易日 15:00 清日线缓存 + 预缓存新数据
  quote TTL 5 分钟（自然过期）
  非交易日不清

手动清理：
  trader.py cache clear → 全部清
  trader.py cache clear --type daily → 只清日线

### 6. 选股池精简为 3 种输出

原来 6 种（show/list/rank/plan/add/remove），精简为 3 种：

- list → 池子概览（合并 show + list）
- plan → 作战表（合并 rank + plan）
- add / remove → 入池出池（不变）

去掉 rank，因为它和 plan 内容 80% 重复。

### 7. 选股池显示加入阶段信息

list 和 plan 输出中，每只票显示大阶段+短期动能：

```
选股池 4/10

宁德时代  主升+修复  执行  触发185.00  防守180.00
南网科技  蓄势+修复  观察  触发57.50   防守56.11
中国铝业  蓄势+震荡  观察  触发12.53   防守12.14
三安光电  蓄势+走强  观察  触发28.30   防守27.00
```

plan 按阶段排序（主升期优先，蓄势期其次），评分放到最后明细里，避免排序和评分不一致造成混淆。

### 8. 入池规则改为四阶段挂钩

原来只看评分（≥70 入池），现在看阶段+评分：

第一关：阶段筛选
  衰退期 → 直接拒绝，不入池
  其他阶段 → 进入评分

第二关：评分门槛
  蓄势期 + 评分 ≥ 70 → 入池，状态「观察」
  蓄势期 + 评分 ≥ 80 → 入池，状态「执行」
  主升期 + 评分 ≥ 60 → 入池，状态「执行」
  派发期 + 评分 ≥ 70 → 入池，状态「观察」（减仓方向）

第三关：风控检查
  现价跌破止损 → 拒绝
  触发位不清楚 → 待补

出池规则：
  手动移除
  阶段从蓄势/主升跌到衰退 → 自动淘汰提醒

### 9. 入池流程优化

原来需要两步操作：
1. trader script --target 南网科技 → 看分析报告
2. trader script add --target 南网科技 → 入池

改为一步操作：
1. trader script --target 南网科技 → 看分析报告
2. 报告末尾显示「当前池 4/10，回复 1 入池」
3. 用户回复 1 → 自动跑阶段判断 + 评分
4. 达标 → ✅ 已加入选股池（蓄势+修复，评分76）
5. 不达标 → ❌ 未入池（衰退期，拒绝）
