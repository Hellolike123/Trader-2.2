### 2. 仓位管理规则

四阶段 + 一条硬规则：

蓄势期：0-30%（试探）
  第一笔 10% → 确认站稳支撑 → 加到 20%
  突破确认 → 阶段转主升

主升期：50-80%（重仓）
  突破确认 → 加到 40%
  回踩不破 → 加到 60%
  持续走强 → 最多 80%

派发期：0-30%（减仓）
  高位滞涨 → 减到 40%
  MACD 顶背离 → 减到 20%
  跌破关键位 → 清仓

衰退期：0%（空仓）

硬规则：持仓亏损时，禁止加仓

### 8. 入池规则改为四阶段挂钩

原来只看评分（≥70 入池），现在看阶段+评分：

第一关：阶段筛选
  衰退期 → 直接拒绝，不入池
  其他阶段 → 进入评分

第二关：评分门槛
  蓄势期 + 评分 ≥ 70 → 入池，状态「观察」
  蓄势期 + 评分 ≥ 80 → 入池，状态「执行」
  主升期 + 评分 ≥ 60 → 入池，状态「执行」
  派发期 + 评分 ≥ 70 → 入池，状态「观察」（减仓方向）

第三关：风控检查
  现价跌破止损 → 拒绝
  触发位不清楚 → 待补

出池规则：
  手动移除
  阶段从蓄势/主升跌到衰退 → 自动淘汰提醒

### 9. 入池流程优化

原来需要两步操作：
1. trader script --target 南网科技 → 看分析报告
2. trader script add --target 南网科技 → 入池

改为一步操作：
1. trader script --target 南网科技 → 看分析报告
2. 报告末尾显示「当前池 4/10，回复 1 入池」
3. 用户回复 1 → 自动跑阶段判断 + 评分
4. 达标 → ✅ 已加入选股池（蓄势+修复，评分76）
5. 不达标 → ❌ 未入池（衰退期，拒绝）

### 13. 仓位轮动逻辑

轮动跟着阶段走，技术指标作为辅助判断轮多少。

核心逻辑：
- 主升期 → 不轮（让利润跑，不管技术指标怎么说）
- 派发期 → 看技术指标决定轮多少（高位钝化/确认突破）
- 衰退期 → 必须清仓（不用看技术指标）
- 蓄势期 → 看技术指标（跟现有逻辑一样）

具体判断：
1. A 派发期 + B 蓄势/主升期 → 轮动
2. A 主升期 + B 任何阶段 → 不轮
3. A 衰退期 + B 任何阶段 → 必须轮（止损/清仓）
4. A 蓄势期 + B 蓄势期 → 看技术指标（高位钝化/确认突破）

轮动比例（保留现有）：
- 风控退出（衰退期跌破止损）→ 清仓
- 强轮动（派发期+候选确认）→ 轮 1/3
- 轻轮动（派发期+候选接近确认）→ 轮 1/6
- 标准轮动（蓄势期高位钝化+候选确认）→ 轮 25%

输出格式：

不轮动时：
```
轮动仓位 — 中国铝业 + 南网科技

🔔 决策：不动

📝 分析
  南网科技在主升期，趋势向上，让利润跑。
  中国铝业在蓄势期，还没突破确认，不急。
  两只票都没有到该动的时候。

📊 持仓
  南网科技：主升+修复 ｜ 现价 59.33 ｜ 浮盈 +64.9%
  中国铝业：蓄势+震荡 ｜ 现价 11.30 ｜ 浮盈 -1.7%

📍 关键价位
  南网科技：确认 62.69 ｜ 防守 56.11
  中国铝业：确认 13.30 ｜ 防守 12.14

👀 触发条件
  南网科技跌破 56.11 → 减仓
  中国铝业站上 13.30 → 可以加仓
```

轮动触发时：
```
轮动仓位 — 中国铝业 + 南网科技

🔔 决策：轮动（轻轮动）

📝 分析
  南网科技进入派发期，高位滞涨，该减了。
  中国铝业进入主升期，突破确认，值得加。
  卖强买弱，轮 1/3 仓位。

📊 持仓
  南网科技：派发+转弱 ｜ 现价 59.33 ｜ 浮盈 +64.9%
  中国铝业：主升+走强 ｜ 现价 13.50 ｜ 浮盈 +17.4%

🔁 轮动方案
  从南网科技减 33%，释放约 7% 总仓
  中国铝业承接 7%，剩余留现金

📍 关键价位
  南网科技：确认 62.69 ｜ 防守 56.11
  中国铝业：确认 13.30 ｜ 防守 12.14

👀 触发条件
  南网科技跌破 56.11 → 清仓
  中国铝业站上 13.30 → 确认突破
```
