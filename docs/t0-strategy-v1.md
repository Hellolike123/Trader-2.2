# T0 日内交易策略 V1.0

> 策略文档（2026-07-25 最终版）

---

## 一、策略概述

基于 **EMA + VWAP + 箱体 + 成交量 + ATR** 五项评分的 A 股日内 T0 策略。

- 数据：5 分钟 K 线（Sina 源，最近 2400 根 ≈ 50 交易日）
- 评分：每项条件 20 分，总分 100 分
- 买入：≥ 40 分可低吸，≥ 60 分强烈，≥ 80 分极强
- 卖出：评分 ≥ 60 或跌破 VWAP 或接近箱体顶
- 止损：ATR×1.5，自适应日线波动，上限 2%
- 入场：信号棒确认后，下一棒开盘价成交

---

## 二、五条件评分

### 条件 1：EMA 排列（20 分）

```
EMA5 > EMA10 > EMA20  → 多头趋势 → +20 分
```

### 条件 2：VWAP（20 分）

```
Close > VWAP  → 高于主力成本 → +20 分
```

### 条件 3：箱体位置（20 分）

```
最近 20 根 5m K 线的最高/最低 = 箱体高/低
距离箱底 ≤ ATR × 0.8  → 靠近支撑 → +20 分
```

### 条件 4：成交量（20 分）

```
Volume > MA5(Volume) × 1.5  → 放量确认 → +20 分
```

### 条件 5：ATR 波动（20 分）

```
ATR(14) / Close > 2%  → 波动足够 → +20 分
```

---

## 四、卖出条件

满足以下**任意一项**即触发卖出：

1. **sell_score ≥ 60**（EMA 空头 + 低于 VWAP + 接近箱顶 + 量 + ATR 的累计分）
2. **Close < VWAP**（跌破主力成本）
3. **接近箱体顶**（距离箱顶 ≤ ATR × 0.8）

---

## 五、风险控制

### 止损

```
止损价 = 持仓最高价 × (1 - ATR×1.5/Close)
科创板 (ATR≈3%)  → 约 2% 止损（上限）
主  板 (ATR≈1%)  → 约 0.5~1% 止损
```

初始止损设在信号棒最低点下方。随后随价格上行**只上移不下移**。

### 止盈

目标位：回归 VWAP（VWAP 均值回归为核心理念）。

### 仓位

由评分决定：

| 评分 | 仓位建议 |
|------|---------|
| ≥ 80 | 50~80% |
| ≥ 60 | 30~50% |
| ≥ 40 | 10~30% |
| < 40 | 0 |
