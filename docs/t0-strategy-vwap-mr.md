## 一、设计动机

前两套策略均亏损，根因是结构问题：

| 策略 | 致命伤 | 结果 |
|---|---|---|
| 评分系统（all3） | 买在 VWAP 上方、卖在下方 → 买高卖低 | 胜率 19%，亏 |
| bb_vwap | 止盈在布林上轨(远~2%)、止损在信号棒低(近~0.3%) → 风险报酬倒挂 | 胜率 17%，亏 |

新策略回归 T0 本质：**抓日内价格围绕 VWAP 的摆动**。价格偏离 VWAP 越远，回归概率越高。

说明：初版曾拍板「止盈=布林上轨」，与盈亏数学（−1% 偏离回归均值）不一致，且 6 棒内几乎触不到上轨。现行实现已改为 **止盈=回归 VWAP**；布林仅作宽度过滤，不作出场目标。`bb_vwap` 模式仍用上轨止盈（属另一套信号脑）。

## 二、核心规则

### 入场（买）
满足以下**全部**条件（`_vwap_mr_eval` → `buy_green`）：
1. `价格 < VWAP × (1 − 1.0%)` — 深偏离主力成本（`VWAP_MR_DEV=0.01`）
2. `当根收盘 > 前收` — 企稳确认，拒绝继续下跌（防抄在半山腰）
3. **非自由落体** — 不是「连跌 + 放量>1.3×」（`FREEFALL_VOL_MULT`）
4. `布林宽 > 0.6%` — 有足够波动可做（`MR_BB_WIDTH_MIN`）

引擎撮合：
- 入场触发只看 `buy_green`（不再叠加旧 `detect_buy_trigger` / `status==已触发` 门控）
- 入场价 ≈ 信号棒收盘 × (1+买滑点)；下一棒开盘附近成交
- 初始止损 = 信号棒最低 × (1−卖滑点)

### 止盈（卖）
- `价格 ≥ VWAP` → `sell_red`，`exit_price = vwap`，限价等待下一棒触及后卖出
- 可选 `--scale-out`：首次触 VWAP **平一半**锁定偏离利润；剩余仓止损抬到保本（含佣金+印花+卖滑点），之后靠追踪止损吃超额。半仓出场**不单独占** `MAX_RT_PER_DAY`；全平（或半仓打光）才计 1 回合

### 时间止损
- **仅** `theory_mode in ("vwap_mr", "momentum_t0")` 启用；`all3` / `bb_vwap` 等其它模式不套用
- 从**成交棒**下标起算（非信号棒）：持仓满 **6 根 5m（30 分钟）**未触发止盈/价格止损 → 市价平
- `momentum_t0` 用更宽的 `MOM_TIME_BARS=10`（50 分钟）
- T0 忌扛单：30 分钟没回归说明判断错，果断砍重来

### 价格止损
- 跌破信号棒低点（初始）+ ATR×1.5 追踪止损（只紧不松，上限 2%）
- `momentum_t0` 改用紧追踪 `MOM_TRAIL=0.8%`

### 费用（引擎记账）
- 单回合约 0.35%：佣金万 2.5 双边 + 印花千 1（仅卖）+ 滑点 0.1%×2
- **买佣金只扣一次**：出场时 `cost = entry × qty × (1 + COMMISSION)`；入场不再预扣（避免双计）

### Regime
- **全 regime 都做**（含下跌日）。不靠趋势过滤，靠企稳确认 + 时间止损防守。

## 三、盈亏数学

- 单回合费用 ≈ 0.35%
- 赢一笔：从 VWAP−1% 回归到 VWAP，毛利 ≈ 1.0%，净 ≈ **+0.65%**（`--scale-out` 若剩余仓继续涨可略多）
- 输一笔：时间止损或打损，常见小亏 ≈ −0.3% − 0.35% ≈ **−0.65%**
- **盈亏平衡胜率 ≈ 50%**（设计预期；回测未达到，见第八节）

## 四、参数

| 参数 | 值 | 说明 |
|---|---|---|
| `VWAP_MR_DEV` | 0.01 | 入场偏差 1.0% |
| `TIME_STOP_BARS` | 6 | 时间止损 6 根 5m = 30 分钟（仅 vwap_mr） |
| `FREEFALL_VOL_MULT` | 1.3 | 自由落体放量阈值 |
| `MR_BB_WIDTH_MIN` | 0.006 | 布林宽下限 0.6%（过滤用，非止盈） |
| `BB_PERIOD` / `BB_STD` | 20 / 2.0 | 布林参数（宽度过滤） |
| `MAX_RT_PER_DAY` | 3 | 每日最多 3 回合 |
| `ATR×1.5` 止损 | — | 上限 2% |
| `--scale-out` | 可选 | 触 VWAP 平一半 + 剩余保本追踪 |

| 出场原因 | 笔数 | 平均盈亏% |
|---|---|---|
| trailing（0.8% 紧追踪被回踩打掉） | 21 | **−0.55%** |

→ 突破信号在 ETF 5m 上**完全没有延续性**，进去即被拉回。

### 8.3 根因

1. **粒度太粗**：5m 棒对 T0 而言太滞后，0.4% 突破 + 0.8% 止损几乎无容错空间。
2. **费用吞噬**：单回合 ~0.35%，要求胜率/盈亏比组合极苛刻（盈亏平衡胜率 ~66%）。
3. **A 股 5m 结构**：ETF 偏均值回归（突破假信号多），趋势股波动大但新高约束过严→信号稀疏。
4. **MFE/MAE 前提误用**：MAE>MFE 来自趋势股诊断，但 ETF（信号频率足够的战场）是另一种结构，直接套顺势不成立。

### 8.5 路径 D：重定义为「降本工具」——硬约束（2026-07-26 收工）

用户最终选 **路径 D：重定义为降本工具**（放弃利润中心定位，定位为持仓优化辅助）。但落笔前必须澄清：

**T0 降本的数学本质**：对同一底仓做高抛低吸，单笔 round-trip 的净盈亏直接加减到持仓成本上——
- round-trip 净赚 → 持仓成本下降（降本 ✅）
- round-trip 净亏 → 持仓成本上升（**升高成本 ❌**，与目标相反）

而我们已证伪：5m 机械信号（vwap_mr PF~0.5 / momentum_t0 盈亏比 0.04–0.27）是**负期望**，round-trip 系统性净亏。
→ **机械执行这套信号做 T0，实际会抬高持仓成本，与「降本」初衷背道而驰。**

**因此「降本工具」定位只在以下两种情况下成立**：

1. **正期望子集才做**：只在胜率 >50% 的高确信 setup 上做 T0。5m 全子集已证伪负期望，需更高门槛或人工过滤——尚未验证。
2. **人工择时**：人看日内结构人工判断高低点，信号脑仅作参考，不自动执行。

**诚实结论**：纯机械 5m T0 既不能做利润中心，也不能做真正的降本工具（因负期望）。合理定位见产品法源 `docs/t0-strategy-v2.md`——
- 实盘 `t0` skill：**日内结构参考**（人决策）
- 回测引擎：`vwap_mr` / `momentum_t0` **保留备查**，默认不自动执行
