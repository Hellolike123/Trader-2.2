## 一、致命问题（P0 — 直接影响决策，必须先修）

### 1.1 同一只票，4 份报告 4 个现价

江西铜业（600362）2026-06-25 01:13 同一分钟采样：

| 报告来源 | 现价 | 偏差 |
|----------|------|------|
| 单票分析报告 | 47.33 | 基准 |
| pool rank | 53.31 | +12.5% |
| pool list 触发价 | 55.17 | +16.5% |
| pool.json current | 46.88 | -0.95% |

**操盘手视角**：如果按 rank 报告 53.31 元下买单，会买在比真实价高 12.5% 的高位，单笔立刻浮亏 6 元/股。这是直接导致爆仓的级别。

**根因**：
- `pool.json` 的 `current` 字段是入池时拍的快照，之后只更新结构字段，不更新价格
- `pool rank` / `pool list` 渲染时直接读 `pool.json`，不重新抓行情
- 只有 `trader analyze` 才走实时行情通道

**修复建议**：
1. `pool list` / `rank` / `plan` 在渲染前，先批量拉一次实时行情（已有 `light_data.py` 可复用），刷新 `current` / `change_pct` 字段
2. 在 `pool.json` 中给每个 item 加 `price_fetched_at` 时间戳，超过 1 小时显示「⚠️ 价格过期」
3. 触发价、止损价、防守位必须随当日 ATR 实时更新，不能是历史快照

### 1.2 触发价严重过期，但仍在出"明日作战表"

池子里 7 只票的触发价 vs 真实现价：

| 票 | 触发价 | 真实现价 | 距离 |
|----|--------|----------|------|
| 禾望电气 | 51.43 | 46.88 | +9.7% |
| 兴发集团 | 36.14 | 34.15 | +5.8% |
| 融捷股份 | 92.04 | 89.74 | +2.6% |
| 赣锋锂业 | 71.85 | 71.16 | +1.0% |
| 江西铜业 | 55.17 | 47.33 | +16.5% |

**操盘手视角**：明日作战表把禾望电气排第一，说"只看 51.43 是否站稳"。但禾望现价才 46.88，要涨 9.7% 才能"站稳触发价"——这等于让用户等一个永远不会来的信号。

**修复建议**：
1. `plan` 渲染时增加过滤：现价距触发价 > 5% 的票，自动从"明日优先级"剔除，转入"远期观察"
2. 触发价需要按最新支撑/压力位动态调整，而非沿用入池时的快照

### 1.3 关键决策指标"数据不足"却仍在出建议

江西铜业单票报告的 `__FACTS__` 字段：

```
risk_reward = "数据不足"      ← 盈亏比缺失
stop_distance = "数据不足"   ← 止损距离缺失
take_pct = "数据不足"        ← 目标收益率缺失
confirm_distance = "数据不足"
ma_trend = "数据不足"
volume_ratio = "数据不足"    ← 量比缺失
momentum_score = "数据不足"  ← 动量评分缺失
```

但报告同时给出：
- `📊 五层打分：结构+40｜量价+30｜筹码50｜动能+50`（动能给了 +50 但 momentum_score="数据不足"）
- `🎯 信号判断：偏多 ✓ 结构（两次接近位置止跌）`

**操盘手视角**：盈亏比是操盘第一指标，没有盈亏比就出"低吸高抛"建议等于让用户盲赌。动能评分缺失却给动能 +50 分，是自欺欺人。

**修复建议**：
1. 任一关键指标（risk_reward / momentum_score / volume_ratio）缺失时，应在报告顶部显示「⚠️ 数据不完整，建议仅供参考」，并降低融合置信度
2. 不允许在 `momentum_score="数据不足"` 时给动能打正分，应显示 `动能 ⚪ N/A`
3. `risk_reward` 应该是必填项，缺失则不出"试探买"建议

## 二、信号自相矛盾（P1 — 看完更迷茫）

### 2.1 同一只票，阶段判定打架

江西铜业：
- 池子（pool.json）：`拉升期 + 走强`
- 单票报告：`蓄势期 + 修复`

这是同一时刻、同一只票、同一份数据，两个完全相反的阶段结论。一个说"主升浪"，一个说"区间震荡"——按哪个操作？

**根因**：池子的 stage 字段是入池时算的，之后从不刷新；单票报告是实时算的。

**修复建议**：池子的 stage_status 必须每次 `plan` / `rank` 时重新计算，不能依赖入池快照。

---

### 2.2 排名结论三套互相打架

| 报告 | Top1 | 理由 |
|------|------|------|
| pool plan | 禾望电气（71 分，最低分之一） | "只看 51.43 是否站稳" |
| pool rank | 赣锋锂业（71.16 元） | "防守观察信号最强" |
| 评分总览 | 江西铜业（88 分，最高） | 但两个报告都没推 |
| 单票报告 | 江西铜业 "等转强观察" | "信号弱轻仓" |

**操盘手视角**：4 个结论 4 个方向。操盘手看 3 份报告比对一次就崩溃了，根本不敢下单。

**修复建议**：
1. 统一排序键：所有池视图（plan/rank/list）必须用同一个排序函数，建议 `融合置信度 × 0.4 + 总分 × 0.3 + 阶段强度 × 0.3`
2. plan 和 rank 的 Top1 必须一致，否则说明排序逻辑有 bug
3. 在每份报告底部加一行「与 rank 视图差异说明」，让用户知道为什么不一致

---

### 2.3 五层打分与价格走势背离

江西铜业当日 -4.13%，但五层打分全正：结构 +40、量价 +30、筹码 50、动能 +50。EXPMA 评"多头排列 9/10 强势"。

**操盘手视角**：跌 4% 的票打全正分，这个打分体系在跌的时候说"强势"，涨的时候也会说"强势"，等于没说。

**根因**：打分基于 MA 排列、缠论笔等滞后指标，没有引入当日涨跌、量价配合度。

**修复建议**：
1. 五层打分增加「当日涨跌方向」修正项：当日跌 > 3% 时，量价分强制归零或转负
2. EXPMA 评分增加"价格与 EXPMA5 的距离"维度：现价低于 EXPMA5 超过 3% 时不能评 9/10

---

### 2.4 回测准确率 0% 但仍用同样规则下结论

`pool rank` 底部：「本月已验证 1 次，对了 0 次，准确率 0%」

但报告继续用同样的"防守观察"信号推荐赣锋锂业。

**操盘手视角**：一个 0% 胜率的策略还在继续出信号，等于送钱。

**修复建议**：
1. 当月验证胜率 < 30% 且样本 ≥ 5 时，在报告顶部加红色警告「⚠️ 策略近期胜率偏低，建议暂停实盘」
2. 推荐结论自动降级：胜率 < 30% 时只给"观察"不给"买入"

## 三、信息密度不足（P2 — 报告不够用）

### 3.1 操盘必备的 7 项数据全部缺失

对照一个真实操盘手下单前要看的清单：

| 操盘手必看 | 当前报告 | 缺失程度 |
|------------|----------|----------|
| 成交量 / 量比 | ❌ 无 | 严重 |
| 换手率 | ❌ 无 | 严重 |
| N 日新高/新低位置 | ❌ 无 | 严重 |
| 距 52 周高低点位置 | ❌ 无 | 中等 |
| 相对大盘强度（RPS） | ❌ 无 | 严重 |
| 所属板块当日表现 | ❌ 无 | 严重 |
| 板块龙头当日表现 | ❌ 无 | 中等 |

**操盘手视角**：没有量能、没有相对强度，等于闭着眼睛看图。一只票"形态再好"但如果所属板块当日跌 3%、龙头跌停，根本不该买。

**修复建议**：
1. 单票报告新增「📊 量能与相对强度」段落，至少包含：
   - 当日量比（vs 5日均量）
   - 当日换手率
   - 距 20 日新高/新低位置
   - 当日相对大盘强弱（个股涨跌% - 大盘涨跌%）
2. 新增「🏭 板块联动」段落：
   - 所属申万二级行业当日涨跌
   - 行业龙头当日表现
   - 个股在板块内的相对排名

---

### 3.2 筹码变化全是"0% 不变"，等于没信息

江西铜业、禾望电气、兴发集团……所有跑过的票，筹码变化都是：
```
47.22（支撑）：8.88% → 8.88%（0%）← 底部筹码不变
50.27（阻力）：3.08% → 3.08%（0%）← 顶部筹码不变
```

**操盘手视角**：筹码搬家是主力出货最早期信号。所有票都"不变"说明算法根本没在算，或者在用同一个空快照对比。

**根因**：`chip_history.json` 的对比基准可能存在问题，或者筹码计算每次都拿到相同输入。

**修复建议**：
1. 排查 `chip_distribution.py` 的输入数据，确认 `turnover_rate` 是否真实
2. 筹码变化连续 3 天显示"0%"时，应在报告里显示「⚠️ 筹码数据异常」而非"不变"
3. 增加筹码集中度指标（如 POC 占比、Value Area 占比）的变化趋势，比单一价位变化更敏感

---

### 3.3 主力行为总是"无数据"

江西铜业：`🔴无数据 ｜ 0/15  资金0/6 ｜ 筹码0/5 ｜ 大单0/4`

最新 commit 已经修了 fallback（从 K 线推导），但实际跑出来还是 0/15。

**操盘手视角**：主力行为是 A 股最重要的维度之一，"无数据"等于自废武功。

**修复建议**：
1. 排查 `calc_fund_flow_features_from_bars` 是否真的被调用、是否真的返回有效特征
2. 即使东方财富 API 不可用，至少基于"放量上涨/缩量下跌"等基础量价规则给一个粗略的主力阶段判断
3. 主力行为完全无数据时，融合置信度应自动降低 50%

## 四、格式与可用性（P3 — 影响阅读体验）

### 4.1 价格阶梯不严格递增

江西铜业单票报告的买卖点排序：

```
45.71 止损
46.88 ← 试探买 10%
47.33 当前
高抛区间 46.81-47.77元    ← 下限 46.81 < 当前 47.33，错！
47.77 → 卖 25%（阻力位）
47.77 压力                ← 与上一行重价
48.05 → 卖 25%（1R保本）   ← 保本卖出价竟高于阻力位
```

**模板规则**：「价格阶梯：买卖点区域从低到高排列」明确要求严格递增。

**修复建议**：
1. 在 `new_render.py` 增加 assert：渲染前检查价格数组严格递增，违反则报错重算
2. "高抛区间"逻辑修复：下限 = max(支撑, 当前价 × 1.005)，上限 = min(阻力, 阻力 × 0.995)
3. "1R保本"卖出价不应高于阻力位，应取 min(1R目标, 阻力位 × 0.99)

---

### 4.2 星级失去区分度

`pool rank` 7 只票全部 ⭐⭐⭐。

**操盘手视角**：星级的意义是"一眼区分"，全员三星等于没星。

**修复建议**：
1. 星级按池内排名分位划分：Top 20% 给 3 星，20-50% 给 2 星，50% 以下给 1 星
2. 或者按融合置信度划分：> 0.6 三星，0.3-0.6 二星，< 0.3 一星

---

### 4.3 仓位建议一刀切

`pool rank` 给所有票都是「仓位 5%」，没有按阶段×ATR×置信度差异化。

**操盘手视角**：拉升期的票和蓄势期的票仓位能一样吗？ATR 8% 的禾望电气和 ATR 5% 的赣锋锂业用同一个 5%？

**修复建议**：
1. 仓位公式：`基础仓位 × 阶段系数 × ATR系数 × 置信度系数`
   - 阶段系数：拉升/主升 1.2，蓄势偏强 1.0，蓄势 0.7，蓄势偏弱 0.4
   - ATR系数：min(1.0, 0.05 / atr_ratio)，ATR 越大仓位越小
   - 置信度系数：fusion_confidence
2. 在 `pool rank` 每只票的仓位行后注明计算依据，如「仓位 5%（蓄势偏强 × ATR 偏高 × 置信 0.6）」

---

### 4.4 多份报告底部结论冲突时无调和

`pool plan` 推禾望电气，`pool rank` 推赣锋锂业，单票报告推江西铜业"等转强观察"。三份报告没有任何一份说明"为什么不一致"。

**操盘手视角**：操盘手看 3 份报告是为了交叉验证，不是为了选自己想看的。冲突时不给调和说明，等于把决策成本全部转嫁给用户。

**修复建议**：
1. 增加 `pool reconcile` 子命令：自动跑 plan / rank / 单票分析，输出差异调和报告
2. 每份报告底部增加「与其它视图的差异」段落，主动暴露不一致

## 六、操盘手视角的"理想报告"长什么样

下面是一份真正能照着下单的单票报告应该有的样子（仅供参考，非改造目标）：

```
分析报告 — 江西铜业（600362）｜ 有色/铜

现价：47.33 元（-4.13%）｜ 量比 0.78 缩量 ｜ 换手 0.9%
距 20 日高：-9.4% ｜ 距 20 日低：+1.4% ｜ 距 52 周高：-23%
MA5：50.44 ｜ MA10：47.77 ｜ MA20：45.82 ｜ MA60：44.30 多头
ATR 3.28（6.9%）波幅偏高 ｜ 大盘今日 -0.8% 个股弱于大盘

📊 蓄势期 + 修复 → 低吸高抛（但今日弱于大盘，建议观察）

🏭 板块联动
  有色/铜 当日 -2.1% ｜ 龙头紫金矿业 -3.5%
  个股在板块 18 只中排名 第 14 位（弱）

融合｜⚪ 等转强观察（加权分 0.00，置信度 9%，信号弱轻仓）

📍 买卖点
  45.71 止损
  46.88 ← 试探买 5%（缩量企稳 + 站上 MA20）
  47.33 当前
  47.77 → 卖 25%（阻力位，与 MA10 重合）
  48.05 压力（1R 目标）
  48.50 确认位（放量突破可加仓）

💡 为什么这么操作
  阶段：蓄势期，但当日弱于大盘 + 板块，等相对强度修复
  量能：缩量回调（量比 0.78），不算崩盘
  位置：现价距 20 日低仅 +1.4%，向下空间有限
  风险：板块龙头跌停概率上升，建议降低首次仓位

📌 持仓建议（无持仓）
  首次试探 5%，跌破 46.88 止损（亏 1R ≈ -1%）
  确认加仓至 10%，突破 48.50 后加至 15%

🔍 主力筹码
  筹码峰：47.22（强支撑 8.88%）｜ 50.27（弱阻力 3.08%）
  当前价以上：53.0% ｜ 中位数：47.12
  筹码变化（对比 5 日前）：底部 47.22 占比 8.88% → 9.21%（+0.33%，缓慢集中）
  POC 控制点：47.22 ｜ Value Area：45.71-50.27

💰 主力行为
  🟡 试盘期（9/15）｜ 资金 4/6 筹码 3/5 大单 2/4
  近 5 日主力净流入：-1.2 亿（小幅流出但未失控）
  大单主动买盘占比：38%

📊 五层打分
  结构 30 ｜ 量价 15 ｜ 筹码 50 ｜ 动能 20 ｜ 相对强度 -10
  缠论：拉升段（置信 0.4）｜ 威科夫：无信号
  扣分项：当日跌 4.13%、弱于大盘、弱于板块

  ⚠️ 偏多但今日背离：结构强但板块弱，建议等板块企稳
  ✅ 亮点：站上 MA20 + 缩量回调 + 底部筹码集中
  ⚠️ 风险：板块龙头走弱 + 个股相对强度排名第 14

盈亏比：1.6（目标 48.50 / 止损 46.88 / 当前 47.33）
当前池 9/10，回复 1 入池
```

关键差异：
1. 多了量比、换手率、N 日高低点位置、相对大盘强度
2. 多了板块联动段落
