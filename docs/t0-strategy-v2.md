**T0 = 持仓者的盘中结构仪表盘。**  
帮助人 1 分钟看清：现价相对何处、空间够不够、今天乱不乱。

## 三、产品目标（成功标准）

| 目标 | 可验收 |
|------|--------|
| 人读得懂 | 无 `#`/`**`/表格；执行卡骨架清晰 |

## 四、输出契约（叙事层）

### 4.1 标题与结论（v2.5）

- 标题：`🎯 名（码）现价x｜VWAPy`  
- 结论语素：**日线威科夫方向**（日线定基调，handoff §1）→（到价）→ 有仓则 `看反T/看正T/观望` + `仓20%-30%` → 或 `宜不做` / `无底仓` → 末尾 `人确认`  
  - 日线积累/markup → `看正T`；日线派发/markdown → `看反T`；无明确阶段 → 按日内箱位（近低正T/近高反T）  
- 数据烂时：`数据不足 · …`  
- **评分不进结论主语**。  
- **禁止**：`三重共振买 → 可低吸`、`可执行 xx～yy`、结论写 `结构偏强(80)` 当主语。

### 4.2 展现顺序（v2.4 行动卡）

固定顺序：

1. **标题**：名/码 + 现价 + VWAP  
2. **结论**：箱位 + `看正T/看反T/观望/宜不做/无底仓` + 仓位 + `人确认`  
3. **【策略基调】**：剧本一句话  
4. **【执行点位与仓位】**：低吸/止损/高抛兑现 + T仓上限 + 14:50  
5. **【盈亏测算】**：默认只按低吸算（止损空间/兑现空间/盈亏比/费后）  
6. **【风控】**：资金倾向 + 倒T不鼓励 + 不越级加仓  

劝退日基调写 `今日宜不做`。无底仓不做T召唤。

### 4.3 信号/评分区（降级为仪表）

- 五条件评分等：一律标为 **参考**；存在于 `plan.resonance` / JSON，**默认 markdown 行动卡可不展开**（v2.4）。  
- 出手依据 = **关键位单信号**（handoff §2：VWAP回归/前高前低突破/开盘价失守收复/AB信号棒，任一 + 顺日线方向即可），评分不驱动 `buy_green`。  
- **不得**把 `buy_green` 映射成交易许可（仍为参考）。  
- 若后续加参考段，文案：`参考分 N · 仅供结构对照`。

### 4.4 剧本内容（有持仓）

- **日线方向优先**（handoff §1）：积累/markup → 正T优先（单日只做正T，不反手）；派发/markdown → 反T优先（单日只做反T，不反手）；无明确阶段 → 日内箱位（近低正T/近高反T，中轴观望）  
- T仓建议底仓 20%–30%（最多一半）+ 约 14:50 前平当日 T 仓  
- 空间不足 / 费后盖不住 / 单边日(|涨跌|≥8%) / 临近涨跌停 / 日均振幅<3% / 日均成交额<3亿 → 结论 `宜不做`

### 4.5 失效/风险

- 「什么情况下今天的结构看法作废」（破 VWAP、破止损参考位等）。  
- 语气：`看法失效` / `今日停`，不是 `止损必须卖`。

## 五、纪律与门控（产品层，非 alpha）

以下是 **使用纪律**，写入 skill/引导即可；不是可回测信号源。

1. **无底仓**：只出 v2.4 行动卡（策略基调→执行点位与仓位→盈亏测算→风控）；不出现「去做 T / 可低吸 / 可执行」主结论。  
2. **有底仓**：同一行动卡骨架；点位/仓位/风控供**人确认**，不下令。旧 `⚡ 今日剧本` 非默认 markdown 主语（见 §4.2 / 验收清单 v2.4）。  
3. **倒 T**：默认不鼓励；仅账户声明有现金且非深套时，文案可提「需自担风险」。  
4. **破位日**：结构结论偏「观望/风控」，不给积极做 T 暗示。  
5. **费用**：单回合成本不可忽视；空间不足时明确写「空间可能盖不住费用」。
