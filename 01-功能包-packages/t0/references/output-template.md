## Structure Card Output

顺序：**标题 → 结论 → 策略基调 → 执行点位与仓位 → 盈亏测算 → 风控**。

```text
🎯 {名}（{码}）现价{px}｜VWAP{vwap}
→ {近低区|近高区|中轴} · {看正T|看反T|观望|宜不做|无底仓} · {仓20%-30%?} · 人确认

【策略基调】
看正T（低吸再卖回）｜现价近买区，待企稳再评估

【执行点位与仓位】
低吸关注：{buy}一带（企稳后再评估）
止损参考：{stop}（跌破则今日停）
高抛兑现：{sell} 或 回到VWAP{vwap}上方
T仓上限：约{n}股（底仓20%-30%）｜14:50前平当日T仓

【盈亏测算】按低吸{buy}算
止损空间：-{risk}（-{pct}%）
兑现空间：+{reward}（+{pct}%）
盈亏比：1比{rr} · 费后约{net}% · 盖得住费用

【风控】
净流入…｜倒T不鼓励｜不越级加仓
```

规则：

- 无底仓：基调写「不做T召唤」；T仓行写「无底仓 · 不做T」
- 劝退日：基调/结论带「今日宜不做」；T仓不动
- 近高区：基调看反T；点位顺序高抛→止损→低吸接回（仍含低吸/高抛/止损关键字）
- 盈亏测算默认只按低吸算（不加现价账）
- 禁止 `可执行` / `可低吸` / `三重共振买` / `先买后卖` / `先卖后买`
- 禁止 `#` / `**` / `---` / `|表格` / `>` / `*-` 列表

### Conclusion

箱位 + 剧本动词 + 仓位 + `人确认`。VWAP 放标题，不进结论主语。评分不进结论。

### 关键字（契约）

全文须出现：`低吸` / `高抛` / `止损`。

## Monitor Alert Output
