## Structure Card Output

有底仓时顺序：**结论 → 今日剧本 → 盘面 → 买卖价/账 → 失效/参考**。

```text
🎯 {名}（{码}）{现价}（{涨跌%}）
→ {位置} · {看反T|看正T|观望|宜不做|无底仓} · {仓位?} · 人确认

⚡ 今日剧本
场景：…
正T看/反T看/卖回看/接回看：…
失效：… → 今日停
T仓：…｜14:50前平当日T仓
账户：成本…｜浮盈/亏…｜费后够/不够｜倒T…
纪律：…

📌 盘面
今日{低}-{高}｜振幅x%｜平量｜VWAPx.xx
{净流入…}          # 可选

📌 买卖价
低吸：{buy}｜止损：{stop}｜高抛：{sell}
波动：ATR {atr}元｜占现价{pct}%
计划账（按低吸{buy}算）：亏a｜赚b → 1比z · 够用/偏弱
  费后约n% · 盖得住｜约x/yATR
现价账（按现价{px}算）：亏c｜赚d → 1比e · 可看/偏弱
  费后约m% · 盖得住

看法失效：跌破止损{stop}
参考分 N · 仅供结构对照
```

无底仓：无 `⚡ 今日剧本`；盘面写 `无底仓 · 不做T召唤`。  
劝退日：剧本折叠为 `今日宜不做：{原因}` + 失效；结论带 `宜不做`。  
仍禁止 `可执行` / `可低吸` / `三重共振买`。不再单独开 `📉 持仓纪律`（并入剧本）。

### 微信排版规则（本卡）

- 禁止 `#` / `**` / `---` / `|表格` / `>` / `*-` 列表
- 用全角 `｜` 分隔同列数字，不用 Markdown 表格
- 结论含剧本动词（看反T/看正T/观望）或宜不做/无底仓，末尾 `人确认`
- 买卖价与剧本关注价同源；评分不进结论主语
- 不写「还差 x% 约 N 根 5m」距离噪音
- 标题代码可去掉 `.SH/.SZ` 后缀省宽度

### Conclusion

位置叙事 + 剧本/仓位；评分不进结论。禁止：`可低吸` / `可执行` / `三重共振买`。

内部状态：`到价关注`（旧 `可执行` 归一化）。

### 买卖价

必须含关键字：`低吸` / `高抛` / `止损`（契约校验）。  
两本账分清基准：`计划账（按低吸算）` vs `现价账（按现价算）`；主行写亏/赚/1比x，次行写费后；禁 `RR1:`。

## Monitor Alert Output

结构提醒话术；禁止做T指令/可执行。
