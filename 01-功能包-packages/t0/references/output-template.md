# Output Template — t0（策略 v2.2 · 微信短卡）

> **This is the absolute truth for valid output.** Never generate output format from memory.  
> 产品法源：`docs/t0-strategy-v2.md`。微信红线见 AGENTS「微信红线」。

## Structure Card Output

```text
🎯 {名}（{码}）{现价}（{涨跌%}）
→ {短结论}

📌 盘面
今日{低}-{高}｜振幅x%｜平量｜VWAPx.xx
无底仓 · 不做T召唤

📌 买卖价
低吸买入：{buy}｜止损：{stop}｜高抛卖出：{sell}
波动：ATR {atr}元｜占现价{pct}%
计划账（按低吸{buy}算）：亏a｜赚b → 1比z · 够用/偏弱
  费后约n% · 盖得住｜约x/yATR
现价账（按现价{px}算）：亏c｜赚d → 1比e · 可看/偏弱
  费后约m% · 盖得住

看法失效：跌破止损{stop}
```

有底仓时在买卖价后可接：

- `📋 做T清单（人勾选）`：反T优先 / 正T备选 / 中轴观望；含 T仓上限与约14:50收盘纪律
- 或 `📋 今日宜不做（人确认）`：空间不足 / 费后盖不住 / 单边日 / 临近涨跌停时折叠清单
- `📉 持仓纪律`：T仓比例 + 收盘平仓 + 费后空间

结论遇劝退时带 `宜不做`；仍禁止 `可执行` / `可低吸` / `三重共振买`。

### 微信排版规则（本卡）

- 禁止 `#` / `**` / `---` / `|表格` / `>` / `*-` 列表
- 用全角 `｜` 分隔同列数字，不用 Markdown 表格
- 结论一行短写：`VWAP上 · 近高区 · 无底仓 · 人决策`
- 买卖价块优先；评分默认不占屏（有分才一行 `参考分`）
- 不写「还差 x% 约 N 根 5m」距离噪音
- 标题代码可去掉 `.SH/.SZ` 后缀省宽度

### Conclusion

位置叙事短词；评分不进结论。禁止：`可低吸` / `可执行` / `三重共振买`。

内部状态：`到价关注`（旧 `可执行` 归一化）。

### 买卖价

必须含关键字：`低吸` / `止损` / `高抛`（契约校验）。  
两本账分清基准：`计划账（按低吸算）` vs `现价账（按现价算）`；主行写亏/赚/1比x，次行写费后；禁 `RR1:`。
