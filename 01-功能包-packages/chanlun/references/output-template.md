# 缠论输出骨架（与 render 同源）

微信安全：面板无 Markdown 标题、粗体、ASCII 竖线表格或水平线；并列使用全角 `｜`。

```text
缠论 — {名}（{码}）｜短中线结构卡
现价 {价}
取数：日{n}根｜周{m}根｜复权{实际口径}｜{数据说明}

⏱ 短线（日）
  结构 {结构或数据不足}｜走势 {引擎走势}｜笔 {n}｜当前笔 {向上笔／向下笔／未形成}｜近笔 {↑↓…}
  中枢 {n}｜段 {n}｜买点 {引擎类型与价或未形成}｜卖点 {引擎类型与价或未形成}

⏱ 中线副读（周）
  结构 {结构}｜走势 {引擎走势}｜笔 {n}｜当前笔 {方向}｜近笔 {↑↓…}
  中枢 {n}｜段 {n}｜买点 {引擎类型与价或未形成}｜卖点 {引擎类型与价或未形成}

💬 说明：本卡只复述缠论引擎结构与买卖点；中线阶段仍由周线威科夫负责
```

周线不足但日线足够时，中线标题必须改为：

```text
⏱ 中线副读（日线 fallback）
```

数据不足时必须直接显示“数据不足”，不得把空买卖点包装成正常中性结构。
