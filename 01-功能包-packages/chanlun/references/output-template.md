# 缠论输出骨架（与 render 同源）

微信安全：面板无 Markdown 标题、粗体、ASCII 竖线表格或水平线；并列用全角 `｜`。  
排版对齐威科夫详析：emoji 分节独立成行，买卖点前置，字段分行，避免竖线墙。

```text
缠论 — {名}（{码}）｜短中线结构卡

📊 现况
  现价：{价}
  取数：日{n}根｜周{m}根
  复权：{实际口径}
  说明：{数据说明}

⚡ 短线（日）
  买点：{引擎类型与价或未形成}
  卖点：{引擎类型与价或未形成}
  结构：{结构或数据不足}
  走势：{引擎走势}
  笔：{n}
  当前笔：{向上笔／向下笔／未形成／笔尖离价降级文案}
  近笔：{↑↓…}
  中枢：{n}｜段：{n}

⏱ 中线副读（周）
  买点：…
  卖点：…
  结构：…
  走势：…
  笔：{n}
  当前笔：…
  近笔：{↑↓…}
  中枢：{n}｜段：{n}

💬 说明
  本卡只复述缠论引擎结构与买卖点
  中线阶段仍由周线威科夫负责
```

周线不足但日线足够时，中线标题必须改为：

```text
⏱ 中线副读（日线 fallback）
```

数据不足时必须直接显示「数据不足」，不得把空买卖点包装成正常中性结构。
买卖点只能来自引擎数组；未形成时写「未形成」，禁止「接近一买」等手补。
类一/类二为观察档，可见面写作「类二买（观察）{价}」；正式一类/二类/三类不加「（观察）」。
