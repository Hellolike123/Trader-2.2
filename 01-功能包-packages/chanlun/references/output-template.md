# 缠论输出骨架（与 render 同源）

微信安全：面板无 Markdown 标题、粗体、ASCII 竖线表格或水平线；并列用全角 `｜`。  
法源：`docs/plans/chanlun-skill-slim-b-handoff.md`。

## 单票 B·中剪卡（默认 `--target`）

与 `render_chanlun_slim` 同源。

```text
{名}（{码}）｜现价 {price}
周线副读：{偏多|偏空|回调偏空|反弹偏多|中性}｜{大结构内本波，如「上涨趋势内回调」}｜{可盯|慎做|先别做}
日线本波：{笔向/主买卖点短句}
入池：{建议入池｜暂不建议入池（短因）｜结构偏空，暂不建议入池}

🧭 周线 · 结构副读
  {周线一句话：走势 · 结构 · 当前笔；fallback 须标「（日线）」}
  灯
  {●|○} 一类买 {price?}
  {●|○} 二类买 {price?}
  {●|○} 三类买 {price?}
  {●|○} 一类卖 {price?}
  {●|○} 二类卖 {price?}
  {●|○} 三类卖 {price?}
  （类一/类二观察档：仅已亮时追加「类×买/卖（观察）{价}」）

⚡ 日线 · 本波
  {日线一句话}
  笔：{n}｜当前笔：…｜近笔：↑↓…
  中枢：{pivot}｜窗{raw}｜段：{n}
  灯
  （同上六灯 + 观察档已亮追加）

🔔 变化
  新亮：…；熄灭：…

🔮 推演
  现在
    周线：{结构一句｜可附「另有类一买（观察，不算正式）」}
    日线：{同上}

  若变好
    周线：{人话：结构先别坏并走出正式买 / 正式买还在…}
    日线：{同上}

  若变坏
    周线：{人话：当前笔被反向打掉或正式卖亮起 / 已有正式卖…}
    日线：{同上}

  ⭐ 盯
    周线：先盯：正式一类买是否形成（或下一档正式买 / 卖点消化）
    日线：{同上}
    本卡不下单；出手/分道看 trader；中线阶段看威科夫
```

`🔔 变化` 仅当有新亮或熄灭时出现；首次记录、无变化、仅仍亮时整块省略。  
灯必须满灯竖排，一行一灯。类一/类二不得冒充正式六灯。  
推演主句只认正式点；观察档只作「不算正式」附注。  
禁止手补买卖点、下单词；中线阶段仍由周线威科夫负责。

## 单票旧薄卡（`--brief`）

与 `render_chanlun_card` 同源。

```text
缠论 — {名}（{码}）｜短中线结构卡

📊 现况
  现价：{价}
  取数：日{n}根｜周{m}根
  复权：{实际口径}
  说明：{数据说明}

⚡ 短线（日）
  买点：…
  卖点：…
  结构：…
  走势：…
  笔：{n}
  当前笔：…
  近笔：…
  中枢：{pivot}｜窗{raw}｜段：{n}

⏱ 中线副读（周）
  …

💬 说明
  本卡只复述缠论引擎结构与买卖点
  中线阶段仍由周线威科夫负责
```

周线不足但日线足够时，中线标题必须为 `⏱ 中线副读（日线 fallback）`。  
数据不足时直接显示「数据不足」；买卖点只能来自引擎数组。
