## 标准渲染样式示例（短中线双轨 · Mobile-First）

```text
分析报告 — 华工科技（000988）｜短中线

（若 data_status≠full，标题后立刻一行：⚠️ 数据不完整…）

📊 价格状态
  现价 48.50（+2.00%）｜MA20 46.00｜MA250 40.00
  综合动能 震荡 ｜ 深成 +0.50% ｜ 电气 -1.20% ｜ 个股 +2.00%
  量比1.2（平量） ｜ 换手4.0% ｜ ATR14 1.20（未复权）

📐 理论分析
  中线
    威科夫：吸筹早期 · 雏形 40.30-43.00（待 ST） · AR（自动反弹） · 不能当已经转强
    缠论：盘整(段偏少)·看跌
    位置：中枢下(反抽中)
  短线
    缠论：顶背驰 · 上攻乏力 · 看跌（本周期）
    买点：已失效（破 8.45，须重走）
    威科夫：无 · 无清晰区间 · 暂定不出 · 仅对照
    事件：ST（二次测试） · 偏多
    动能：震荡 · 中性
    资金：主力5日流出-1200万

🎯 支撑阻力
  中线
    生命线 40.00（破则中线转弱）
    回踩区 44.00-46.00（到了才谈低吸）
    压力 51.00（靠近只减不加）
    目标 55.00（波段上看）
  短线
    止损 44.00（破则今日计划作废）

  作废：破止损 44.00

✅ 亮点：短线威科夫可跟踪，先看低吸区再动手
⚠️ 风险：现价不宜追；止损看 44.00，上方压力约 51.00
📌 本周只做：不追现价；回低吸区再谈
当前池 3/10，回复 1 入池
```

## 格式规则（短中线双轨 + 纪律）

- **标题**：`分析报告 — {名}（{码}）｜短中线`
- **主题顺序**：`📊 价格状态` → `📐 理论分析` → `🎯 支撑阻力` → `✅ 门禁` → 尾部；子块只用纯文 `中线` / `短线`，不再用 🧭/⚡ 作主分区
- **📊 价格状态**：MA 行须含 MA20 与 MA250；`综合动能 … ｜ {上证/深成/创业板/科创} ±x% ｜ {行业短名} ±x% ｜ 个股 ±x%`（纯 D：不写正常/偏弱/跑赢；环境档跟板块指数算但 meta 不露）；量价行：`量比… ｜ 换手… ｜ 调整N天/创新高 ｜ ATR14 x.xx（前/后/未复权）`（ATR **并入同行**，禁止再单独成行）
- **📐 理论分析 · 中线**
  - 禁止独立 `阶段：` / `定论：` 行；阶段信息只留在 `威科夫：` 正文
  - `威科夫：` ← 只读周线 `wyckoff_midline` / View（`format_wyckoff_midline_light`）；结构「阶段 · [箱体/雏形] · 事件 · 含义」；禁止回退日线
  - 仅 L3 在威科夫下追加 `下沿 x｜上沿 y（L3）` 与 `量度目标：上 x｜下 y（P&F/高度1:1，非出手）`；L0-L2 不贴量度行，也不写「未达 L3」解释行
  - `缠论：` ← 只读 `chanlun_midline`；有买卖点/背驰时行尾 `（本周期）`；周不足可 daily_fallback+「（日线）」；不定阶段
  - 可选 `位置：` ← `pivot_position_weekly`（中枢内/上/下/外/未知）
- **📐 理论分析 · 短线**
  - 顺序：`缠论` → `买点?` → `威科夫` → `L3 下沿/上沿?` → `L3 量度目标?` → `事件?` → `动能` → `资金`
  - `缠论：` ← 日线缠论扳机（与中线点名同构；主信号最多三段）
  - `威科夫：` ← 日线威科夫**只对照**（标签固定威科夫，**禁止**「日线阶段：」；`箱体 lo-hi` / `雏形…（待 ST）` / 无清晰区间；正文带「仅对照」）；**不进**背景岗/fusion/出手
  - 仅日线 L3 在威科夫下追加下沿/上沿与量度目标；L0-L2 省略
  - `事件：` ← 日线威科夫事件灯（AR/Spring…）
  - `动能：` / `资金：` **分行**（禁止再并成一行长句）
- **🎯 支撑阻力**
  - 中线：生命线 / 回踩区 / 压力 / 目标，来源 `mid_key_prices`（周线引擎），**无 🌟**
  - 短线：止损 / 低吸区（或买点区） / **🌟 现价** / 卖点区，来源 `key_prices`；亏赚两句挂短线支撑阻力后
  - 可选 `日内 T0：…` 挂短线支撑阻力后；已输出则尾部不重复
  - 禁止在本区展示 `量度目标` / `P&F` / 威科夫 L3 下沿上沿
- **✅ 门禁**（判定仍听 `decision_view`；只改展示）
  - `结论：` `不新开 · 仓 0%` 或 `可试探 · 仓 x%`
  - `还差：` 共振缺岗 + C1 缺项合并去重；全齐省略；>5 项折叠 `另N项`
  - `等待：` 现价已破生命线 → `收回生命线 x（现价已破）`；否则 `站稳 confirm`；再否则可 `不追现价`
  - `作废：` 空仓只写 `破止损 x`（与短线止损同号）；禁止现价已低于 MA20 仍写「跌破MA20…」
  - `附：` 亏赚/不划算/偏冲高等；可省略
- **纪律（只收紧）**
  - 开仓清单：中线趋势｜回踩到位｜买点信号｜融合置信｜筹码资金稳（全绿才可试探；融合置信≠方向一致）
  - 一买试/二买加/三买主仓阶梯；盘整禁趋势重仓；短线 low_zone 门禁；破生命线/中枢/周框破坏不新开
  - `suggested_pct` 与 `position_info.suggested_pct` 先被 merge cap 裁切；若 `decision_view` 禁止新开则**归零**（展示「仓 0%」）
- **禁止**：🎯 结论、🗳️ 短线专家、🗺 空间参考、mi姐/Mistery 人设
- **门禁判定**：听 `decision_view`（共振∧策略∧纪律）；中线目标不得单独放行买；门禁价须能在支撑阻力找到同号
- **Fixed Keywords**：必须含「止损」和「买」

## 分层语义（禁止混淆）

| 层 | 含义 | 数据源 |
|----|------|--------|
| 阶段（威科夫正文内，不单独成行） | 周线威科夫短词，中线背景语义 | wyckoff_midline.phase → stage_line / midline_stage |
| major_stage | 日线四阶段，门控/池软信号（**不**写中线「阶段：」行） | major_stage |
| short_term_momentum | EXPMA 短期动能（走强/修复/震荡/转弱） | assess_stage → momentum |
| report["stage"] | **兼容别名 = short_term_momentum**（池/旧读方；非 major_stage） | 同 short_term_momentum |
| 理论分析·中线 | 周线故事跟不跟 | chanlun_midline + wyckoff_midline |
| 支撑阻力·中线 | 生命线/回踩/压力/目标 | mid_key_prices（周线引擎） |
| 理论分析·短线 | 日线结构、对照与确认 | chanlun / daily wyckoff / momentum / fund |
| 门禁 / 作废 | 今天动不动手、何时作废 | decision_view + 纪律门控 + key_prices / mid_key_prices |
| 支撑阻力·短线 | 止损/买点/卖点 | key_prices |

## 回退

## 选股日报格式 (pool briefing / daily report)

当用户要求批量分析多只股票时，输出选股日报。脚本入口: `pool_briefing.py`。

格式：竖排，每只 2-3 行，按推荐买入/重点关注/暂时不看分组。
选股池正式排序：`lane→共振→链→RS→可碰→分`（`sort_items_unified`）。  
组内简报（`pool_briefing`）次键为共振档→结构总分+阶段，**不含**链/RS（见该脚本 docstring）；`fusion.weighted_score` 仅展示，不参与排序。

```text
选股日报 — 2026-06-17 ｜ 大盘偏弱
（池日报仍用宽基 INDEX_CODE 环境档文案；单票报告 meta 见上文纯 D，不写「大盘」）

推荐买入（2只）

🥇 天齐锂业 688248.SH 52.30（+1.80%）
  蓄势 持股观望 结构强 量价健康 EXPMA7/10 共振6/10
  买49.50 压54.80 损47.20
```
