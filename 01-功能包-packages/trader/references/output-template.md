## 标准渲染样式示例（短中线双轨 · Mobile-First）

```text
分析报告 — 华工科技（000988）｜短中线

（若 data_status≠full，标题后立刻一行：⚠️ 数据不完整…）

现价 48.50（+2.00%）
  动能 震荡 ｜ 大盘 偏弱
  MA5：47.00 ｜ MA20：46.00 ｜ MA250：40.00
  量比1.2（平量） ｜ 换手4.0%

🧭 中线
  阶段：蓄势偏强
  看法：盘整偏空 · 暂缓跟踪
  威科夫：暂无事件·中性
  缠论：盘整(段偏少)·看跌
  位置：中枢下(反抽中)

  关键价（中线）
    生命线 40.00（破则中线转弱）
    回踩区 44.00-46.00（到了才谈低吸）
    压力 51.00（靠近只减不加）
    目标 55.00（波段上看）

⚡ 短线
  看法：不适合追，偏冲高减
  缠论：顶背驰 · 看跌（同级）
  位置：中枢外
  动能：震荡 · 中性
  价量资金：放量滞涨（资金未取到） · 看跌
  裁定：偏空，不宜追高
  新开：否（缺：回踩到位｜买点信号）
  出手：现价不买 · 不追（现价追大约亏 4.5、赚 0.5，不划算）
  分仓：中线≤0% ｜ 短线≤0% ｜ 总≤0%
  失效：收盘有效跌破MA20(46.00)且反抽站不回；或跌破止损 44.00

  关键价（短线）
    止损 44.00（破则今日计划作废）
    买点区 44.90-45.20（回这里再谈买）
    🌟 现价 48.50
    卖点区 46.00-49.00（冲到减/高抛）

  45.05 买：亏约 1.1 / 赚约 4.0（远看 9.9）
  48.50 追：亏约 4.5 / 赚约 0.5 → 不追

说明：周线偏空，短线也不追
✅ 亮点：日线阶段 蓄势偏强，先看短线买点再动手
⚠️ 风险：现价不宜追；止损看 44.00，上方压力约 51.00
📌 本周只做：不追现价；回买点再谈
T0：无底仓，不启用（与出手一致，不新开）
当前池 3/10，回复 1 入池
```

## 格式规则（短中线双轨 + 纪律）

- **标题**：`分析报告 — {名}（{码}）｜短中线`
- **meta**：动能｜大盘；MA 行须含 MA20 与 MA250；阶段主展示在 🧭
- **🧭 中线**
  - `阶段：` ← major_stage（入池/轮动/纪律输入；算法不改）
  - `看法：` ← 周线 chanlun_midline + wyckoff_midline（B1A）；**禁止**四阶段词
  - 威科夫 / 缠论：只读 `*_midline`，禁止回退日线；有买卖点/背驰时缠论行尾 `（同级）`
  - 可选 `位置：` ← `pivot_position_weekly`（中枢内/上/下/外/未知）
  - 关键价（中线）：生命线 / 回踩区 / 压力 / 目标；**无 🌟**（周线引擎）
- **⚡ 短线（A 版读序）**
  - 顺序：`结构` → `状态` → `动能｜资金` → `动作` → `失效` → 关键价
  - `结构：` ← `format_chanlun_short_light`：一买/二买/… 或 底背驰 · 方向 · 同级；进 fusion
  - `状态：` ← `wyckoff_daily` / `format_wyckoff_event_light`：英文灯 + 中文；只展示不评分
  - `动能：… ｜ 资金：…` ← momentum + vpf（同意/不同意一眼看）
  - `动作：` ← 纪律裁完计划（不新开 / 等站稳价 / 仓 x%）；**不用「出手」**
  - `失效：` ← 纪律 invalidation
  - 中线 `威科夫：` 仍只读 `wyckoff_midline`（阶段叙事）
  - 关键价（短线）：止损 / 买点 / **🌟 现价** / 卖点 + 亏赚两句
- **纪律（只收紧）**
  - 开仓清单：中线趋势｜回踩到位｜买点信号｜融合置信｜筹码资金稳（全绿才可试探；融合置信≠方向一致）
  - 一买试/二买加/三买主仓阶梯；盘整禁趋势重仓；短线 low_zone 门禁；破生命线/中枢/周框破坏不新开
  - `suggested_pct` 与 `position_info.suggested_pct` 同步被 cap 裁切
- **说明**：仅中短冲突时
- **禁止**：🎯 结论、🗳️ 短线专家、🗺 空间参考、mi姐/Mistery 人设
- **出手**：纪律门控裁动作；中线目标不得单独放行买；**不改价**
- **Fixed Keywords**：必须含「止损」和「买」

## 分层语义（禁止混淆）

| 层 | 含义 | 数据源 |
|----|------|--------|
| 阶段 | 主力四阶段，中线仓位语义 | major_stage |
| 中线看法 | 周线故事跟不跟 | chanlun_midline + wyckoff_midline |
| 中线关键价 | 生命线/回踩/压力/目标 | mid_key_prices（周线引擎） |
| 短线看法/专家 | 追不追 | fusion 日线 |
| 出手 / 失效 | 今天动不动手、何时作废 | 纪律门控 + key_prices |
| 短线关键价 | 止损/买点/卖点 | key_prices |

## 选股日报格式 (pool briefing / daily report)

当用户要求批量分析多只股票时，输出选股日报。脚本入口: `pool_briefing.py`。

格式：竖排，每只 2-3 行，按推荐买入/重点关注/暂时不看分组。
组内排序：共振档 → 结构总分+阶段（与选股池 `sort_items_unified` 对齐）；`fusion.weighted_score` 仅展示，不参与排序。

```text
选股日报 — 2026-06-17 ｜ 大盘偏弱

推荐买入（2只）

🥇 天齐锂业 688248.SH 52.30（+1.80%）
  蓄势 持股观望 结构强 量价健康 EXPMA7/10 共振6/10
  买49.50 压54.80 损47.20
```
