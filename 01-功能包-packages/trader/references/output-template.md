## 格式规则（短中线双轨 + 纪律）

- **标题**：`分析报告 — {名}（{码}）｜短中线`
- **顶栏 A**：①`现价…｜MA20｜MA250` ②`环境：{宽基指数} ±% ｜ {主交易板块指数?} ±% ｜ 强于/弱于/持平板块 …`（**无个股绝对%**，现价行已有；相对板块用超额涨跌；不写正常/偏弱/跑赢；**位置不进环境**）③`概念：标签1 ｜ 标签2 ｜ 标签3`（身份；无概念则省略；**禁止**概念假指数涨跌）④`量能：量比… 平/放/缩 ｜ 换手? ｜ 调整N天/创新高 ｜ 位置 … ｜ ATR14 x.xx`（位置+ATR 并入量能行；无独立 ATR 行；默认无资金面；|两融净买|≥5000万才点名 `两融：`）；阶段主展示在 🧭
- **板块 vs 概念（数据）**：比较尺子 = 有真实日线的同花顺板块/行业指数（唯一）；概念 = 标签 + 映射线索（如磷酸铁锂→电池化学品），见 `sector_data.get_stock_sector_snapshot`
- **🧭 中线** / **⚡ 短线** 标题挂灯：`🧭 中线｜🔴 防守` / `⚡ 短线｜🔴 不新开`（🟡 观望/仅观察，🟢 可跟踪/去看trader；绿=资格非可买；不写「操作灯」三字）
- **🧭 中线**
  - **无**独立 `阶段：` 行（阶段细读见下方 `威科夫：`；字段 `midline_stage` / `stage_line` 仍钉周线威科夫短词供共振，不足→`无阶段`）；**禁止**日线 `major_stage` / 缠论方向矩阵冒充
  - **无** `定论：` 行（威科夫/缠论分行自读；`midline_verdict_note` 仅字段/池侧，不进面板）；**禁止**独立 `看法：` 行
  - `威科夫：` ← 只读周线 `wyckoff_midline` / View（`format_wyckoff_midline_light`）；结构「阶段 · [箱体] · 事件 · 含义」；箱体与短线同款（`箱体 lo-hi` / `箱体未成形 · 下沿…（上沿未出）`）；禁止回退日线
  - **无** `附：股东户数` / `业绩预期`（默认不进主面板）
  - `缠论：` ← 只读 `chanlun_midline`；有买卖点/背驰时行尾 `（本周期）`；周不足可 daily_fallback+「（日线）」；不定阶段
  - 可选 `位置：` ← `pivot_position_weekly`（中枢内/上/下/外/未知）
  - 关键价（中线）：**价格升序阶梯**（价在前）；生命线/黄金/MA20/MA250/近压；**无 🌟**；最多约 6 档；**严格价格升序、价在前**；偏空/关闭态**不挂远档结构**；非 genuine（max 兜底）远档不上梯；距现价 **>+30%** 的压力/远档不进阶梯；文案用「远档结构·仅对照」，禁止「目标止盈」；关闭态/偏空禁「低吸」动词
- **⚡ 短线（A 版读序 · 窄屏扫读）**
  - 顺序：`缠论` → `买点?` → `威科夫`（含事件）→ `动能` → `资金` →（空行）→ `共振/新开` → `动作` → `原因?` → `破位看` → 关键价
  - `缠论：` ← 日线缠论扳机（与中线点名同构；主信号最多三段）
  - 关键价（短线）：**价格升序阶梯**；**严格价格升序、价在前**；关闭态=止损+MA5?+现价+站稳线（confirm），**不铺**计划买区/VWAP/止盈旅游图；放行态才出低吸区/止盈区（区间写作 `41.93-42.98 低吸区`）
  - `威科夫：` ← **日线短波侧**（`infer_daily_short_wave`）：先定吸筹/派发侧，再写该侧主灯（如 `短波派发 · LPSY偏空@x` / `短波吸筹 · SOS偏多@x`）；未成型回退箱体/对照 light；与阶段/箱体**并一行**；标签固定威科夫，**禁止**「日线阶段：」与独立「事件：」；短波已含主灯时不叠反向事件；尾注统一「不作买点」；**不进**背景岗/fusion/出手
  - `动能：` / `资金：` **分行**（禁止再并成一行长句）
  - `动能：` ← `fusion.signals_detail.momentum.direction` 总词（`1/bullish→偏强`、`-1/bearish→偏弱`、`0/neutral→中性`）· 原始 reason；无 direction 或 reason 含“数据不足”不硬加；`中性 + 动量中性` 只显示 `动能：中性`
  - `资金：` 有依据时前置 `买盘占优/卖盘占优 · `：大单字段优先；其次 `cum_flow_5d_wan`（`|x|>=100` 万）或 `cum_flow_10d_wan`（`|x|>=3000` 万）符号；无依据保持原资金行
  - 决策块前空一行：看盘 ↑ / 能不能做 ↓
  - `共振：` 白话「未齐 · 还差…」；禁止「缺结构（缺：结构）」叠词
  - `新开：` `先别买 · 人话缺项` 或 `可试探 · 五项齐了`
  - `动作：` 只写做什么；亏赚/不划算进 `原因：`；**不用「出手」**
  - `破位看：` ← 纪律 invalidation（有仓/盯盘线；无仓=计划作废线）
  - 关键价（短线）：止损 / 买点 / **🌟 现价** / 卖点；关闭态不铺计划买区（止损+MA5+现价+站稳线）、MA5=`观察`、无仓现价=`不追`（禁低吸/加仓/持有勾引）
  - `T0：` 无仓+关闭态一律 `无底仓，不启用（与出手一致，不新开）`；禁止再打日内低吸/高抛
- **纪律（只收紧）**
  - 开仓清单：中线趋势｜回踩到位｜买点信号｜融合置信｜筹码资金稳（全绿才可试探；融合置信≠方向一致）
  - 一买试/二买加/三买主仓阶梯；盘整禁趋势重仓；短线 low_zone 门禁；破生命线/中枢/周框破坏不新开
  - `suggested_pct` 与 `position_info.suggested_pct` 先被 merge cap 裁切；若 `decision_view` 禁止新开则**归零**（展示「仓 0%」）
- **说明**：仅中短冲突时
- **禁止**：🎯 结论、🗳️ 短线专家、🗺 空间参考、mi姐/Mistery 人设
- **出手**：听 `decision_view`（共振∧策略∧纪律）；中线目标不得单独放行买；**不改价**
- **Fixed Keywords**：必须含「止损」和「买」

## 分层语义（禁止混淆）

| 层 | 含义 | 数据源 |
|----|------|--------|
| 阶段（字段 `midline_stage`；面板不单独成行） | 周线威科夫短词，中线背景/共振 | wyckoff_midline.phase → stage_line / midline_stage |
| major_stage | 日线四阶段，门控/池软信号（**不**写中线展示） | major_stage |
| short_term_momentum | EXPMA 短期动能（走强/修复/震荡/转弱） | assess_stage → momentum |
| report["stage"] | **兼容别名 = short_term_momentum**（池/旧读方；非 major_stage） | 同 short_term_momentum |
| 中线看法 | 周线故事跟不跟 | chanlun_midline + wyckoff_midline |
| 中线关键价 | 生命线/回踩/近压/（可选）远档结构 | mid_key_prices（周线引擎） |
| 短线看法/专家 | 追不追 | fusion 日线（仪表；出手听 decision_view） |
| 出手 / 失效 | 今天动不动手、何时作废 | decision_view + 纪律门控 + key_prices |
| 短线关键价 | 止损/买点/卖点 | key_prices |

单票**始终**中短线双轨（`render_short_midline`）。`SHORT_MIDLINE_REPORT=false` **已忽略**，无法回退旧 `🎯`+`📍 决策` 面板。

## 选股日报格式 (pool briefing / daily report)

当用户要求批量分析多只股票时，输出选股日报。脚本入口: `pool_briefing.py`。

格式：竖排，每只 2-3 行，按推荐买入/重点关注/暂时不看分组。
选股池正式排序：`lane→共振→链→RS→可碰→分`（`sort_items_unified`）。  
组内简报（`pool_briefing`）次键为共振档→结构总分+阶段，**不含**链/RS（见该脚本 docstring）；`fusion.weighted_score` 仅展示，不参与排序。

```text
选股日报 — 2026-06-17 ｜ 大盘偏弱
（池日报仍用宽基 INDEX_CODE 环境档文案；单票报告 meta 见上文纯 D，不写「大盘」）

推荐买入（2只）

🥇 天齐锂业 688248.SH 52.30（+1.80%）
  蓄势 持股观望 结构强 量价健康 EXPMA7/10 共振6/10
  买49.50 压54.80 损47.20
```
