# Trader 核心报告样式与文案契约 (2.5.0 短中线)

> **This is the absolute truth for valid output.** Never generate output format from memory.

本模板为 `trader` 命令 (`final_report.py`) 的绝对输出契约。生产渲染入口：`trader_shared.report_core.render_single` → 默认 `render_short_midline`。

> **变更记录 (v2.5.0 短中线 + Mistery 门控)**：
> - 标题后缀：`｜短中线`
> - 结构冻结：现价元信息 → 🎯 结论 → 🗳️ 日线三专家+日线裁定 → 📍 关键价+两句亏赚 → 🗺 空间参考 → ✅⚠️📌 T0 池
> - Mistery 门控只作出手/仓位裁切，**禁止**改写 major_stage / fusion 分 / support / stop
> - 买卖点始终输出，不依赖 has_position
> - 空仓禁止主结论只写「减仓」→ 译为不宜追高/不新开
> - 主卡不展示加权分；无独立门控 YAML 块
> - 回退：`SHORT_MIDLINE_REPORT=false` 使用旧 `render_single_legacy` 模板
>
> **变更记录 (v2.4.2 威科夫展示)**：
> - 威科夫理论行改为一行人话：`威科夫：{结论}，{偏多|偏空|中性}（{白话说明}）`
> - `🎯` 在短中线模板为「结论」区块；旧模板中 `🎯` 仍为主力四阶段（major_stage）

⚠️ **格式红线 (CRITICAL)**：
1. **禁用所有 Markdown 标题与水平线**：严禁使用 `#` 级标题或 `---`。各段落必须通过一个空行和 Emoji 前缀的纯文本直接分隔。
2. **禁用表格与加粗**：如需突出显示，只能使用空格/全角竖线排版，绝对禁止使用 Markdown 表格语法 `|...|` 和加粗语法 `**...**`。
3. **首行强制规范**：输出的首行必须是 `分析报告 — 标的名称（代码）｜短中线`（短中线模式）或 `分析报告 — 标的名称（代码）`（旧模板回退）。
4. **必须保留的关键字符串**：下游组件验证依赖特定关键词，在排版时请务必确保报告中包含「止损」和「买」。
5. **竖屏友好**：一行一个数据点，不用逗号分隔多个数据。适合手机竖屏阅读。
6. **禁止 R:R 术语**：主报告不得写「2.1R」「不足 1R」；亏赚用人话两句。

## 格式规则（短中线）

- **标题**：`分析报告 — {名}（{码}）｜短中线`
- **元信息**：阶段｜动能｜大盘；MA 行须同时含 MA20 与 MA250（无值用 `--`）
- **🎯 结论**：中线看法 / 短线看法 / 出手 / 原因 / 本周；说明仅中线 vs 短线冲突时输出
- **出手**：来自 Mistery 门控人话；空仓时「减仓/止损离场」译为「不宜追高 · 不新开」
- **🗳️ 日线三专家**：缠论 / 动量 / 威科夫 + 日线裁定（偏多|偏空|中性 + 宜追|不宜追高|观望）；**不展示加权分**
- **📍 关键价**：止损卖点、买点区、现价、短线卖点区、波段卖点区；**不看仓位始终输出**
- **两句亏赚**：
  - `{buy_ref} 买：亏约 X / 赚约 Y（远看 Z）`
  - `{px} 追：亏约 A / 赚约 B → 不追|可考虑`
- **🗺 空间参考**：近端｜波段｜远端，标注「不指挥下单」
- **Fixed Keywords**：报告必须含「止损」和「买」
- **Banned Terms**：DO NOT output "必涨", "必跌", "主力入场第一枪", "出货日", "行情结束" and others listed in schema/v1.py
- **段落分隔**：每个 Emoji 段落之间空一行，段落内数据紧凑不空行

## 分层语义（禁止混淆）

| 层 | 含义 |
|----|------|
| 中线看法 | 故事在不在，来自 major_stage 等；不是日线 fusion 单独清仓 |
| 短线看法 | 追不追，来自 scene + 日线裁定 |
| 出手 | Mistery 门控 + 现价相对买点 + 人话亏赚 |
| 关键价 | 买卖点地图，与 has_position 无关 |

## 选股日报格式 (pool briefing / daily report)

当用户要求批量分析多只股票时，输出选股日报。脚本入口: `pool_briefing.py`。

格式：竖排，每只 2-3 行，按推荐买入/重点关注/暂时不看分组。

🥇 天齐锂业 688248.SH 52.30（+1.80%）
  蓄势 持股观望 结构强 量价健康 EXPMA7/10 共振6/10
  买49.50 压54.80 损47.20

🥈 禾望电气 601899.SH 18.60（+2.10%）
  蓄势 持股观望 结构强 筹码锁定 EXPMA6/10 共振4/10
  买17.80 压19.50 损17.20

重点关注（2只）

🥉 恩捷股份 45.20（-0.80%）
  转弱 持股观望 结构强 量价健康 量价弱 EXPMA3/10
  买43.50 压47.00 损42.80
  等转强

4 融捷股份 46.80（-1.20%）
  修复 持股观望 结构强 筹码锁定 量价弱 EXPMA4/10
  买44.50 压49.00 损43.50

- 按融合加权分数从高到低排序
- 排名用 🥇🥈🥉 或数字（3以后用数字）
- 移动端竖排友好：无表格、无加粗、无水平线、无 Markdown 标题
