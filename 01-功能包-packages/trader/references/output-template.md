# Trader 核心报告样式与文案契约 (2.4.0)

本模板为 `trader` 命令 (`run_analysis.py`) 的绝对输出契约。所有渲染层修改必须且只能参照以下样例进行，禁止随意添加中间调试信息（如融合层 JSON 输出）、大盘段落、以及不相关的格式符号。

⚠️ **格式红线 (CRITICAL)**：
1. **禁用所有 Markdown 标题与水平线**：严禁使用 `#` 级标题或 `---`。各段落必须通过一个空行和 Emoji 前缀的纯文本直接分隔。
2. **禁用表格与加粗**：如需突出显示，只能使用空格/全角竖线排版，绝对禁止使用 Markdown 表格语法 `|...|` 和加粗语法 `**...**`。
3. **首行强制规范**：输出的首行必须是 `分析报告 — 标的名称（代码）`。
4. **必须保留的关键字符串**：下游组件验证依赖特定关键词，在排版时请务必确保报告中包含“试探买”和“止损”。

## 标准渲染样式示例 (Ultra-Simplified)

```text
分析报告 — 南网科技（688248）

现价：58.50元（-3.50%）
MA5：59.05｜MA10：60.58｜MA20：61.02｜MA30：59.85
ATR 3.69（6.1%）波幅偏高

📊 蓄势期 + 转弱 → 低吸高抛

融合｜🟢 增持（加权分 0.32，置信度 72%）
融合｜🟠 减仓（加权分 -0.18，置信度 65%）

📍 买卖点
  55.57 止损
  57.61 ← 试探买 10%（缩量企稳）
  58.20 ← 黄金挂单（斐波那契61.8%）
  58.50 当前
  59.22 → 卖 33%（阻力位）
  62.85 → 卖 33%（1R 目标）
  62.87 压力
  阶段转派发 → 清仓

💡 为什么这么操作
  阶段：蓄势期（区间震荡，低吸高抛）
  趋势：短期偏弱（价格在 59.00 下方），不追

📌 如果你有持仓（成本 60.00）
  现在：持有，不加仓（亏 2.5%）
  反弹到 60.00：减 50%（保本）
  跌破 55.57：止损（认亏）

🔍 主力筹码
  筹码峰：
    57.88（支撑）｜ 占比 5.91%
    60.46（强阻力）｜ 占比 6.99%
    63.05（弱阻力）｜ 占比 5.29%
  当前价以上：67.3%
  中位数价格：60.29

  筹码变化（对比昨天）：
    57.88（支撑）：5.91% → 4.50%（-24%）← 底部筹码减少
    60.46（阻力）：6.99% → 8.50%（+22%）← 顶部筹码增加
    结论：筹码在搬家，主力在出货

💰 主力行为 ｜ 🟢主力强势（13/15）
  资金 5/6 ｜ 筹码 4/5 ｜ 大单 4/4
  ·连续5日主力净流入
  ·价跌资入（健康吸筹）
  ·买方更强

📊 五层打分
  结构75/量价45｜筹码50｜动能50
  缠论：回调段。一类买、二类买
  威科夫：无明显威科夫信号

  EXPMA：多头排列（6/10）
  EXPMA5=58.20, EXPMA10=57.80, EXPMA20=57.50, EXPMA50=56.80
  多窗：部分共振（4/10）
  周日线代理多头（站上） ｜ 日线偏多（安全位）

📊 股性与历史回测
  买入信号 12次 ｜ 8胜4负 ｜ 胜率 67% ｜ 平均 +4.2%
  卖出信号 5次 ｜ 3胜2负 ｜ 胜率 60% ｜ 避坑 -2.1%
  ⚠️ 样本不足，仅供参考

🎯 信号判断
  偏多：✓ 结构（两次接近位置止跌）
  警惕：! 量价（午后缩量）  ! 筹码（上方成交密集区）

✅ 亮点：58.50 仍站在防守位 57.61 上方
⚠️ 风险：筹码在搬家，主力在出货，警惕继续下跌

当前池 3/10，回复 1 入池
```

- **ATR**: Displayed if > 0.
- **Fusion Verbatim**: MUST include the `融合｜{emoji} {action}（加权分 X.XX，置信度 XX%）` line between the stage summary and 买卖点 section. Use `fusion.fusion_verbatim` from JSON directly; do NOT paraphrase.
- **Fixed Keywords**: The output MUST contain exactly "试探买" and "止损" to pass automated validation.
- **黄金挂单**: If `fib_retrace.golden_bid` is valid and differs from the low_zone price, render a line: `{price} ← 黄金挂单（斐波那契{比例}）` between "试探买" and "当前", e.g. `58.20 ← 黄金挂单（斐波那契61.8%）`.
- **Chip Migration**: MUST include a comparison to the previous day ("对比昨天"), reflecting changes in support and resistance peaks.
- **Banned Terms**: DO NOT output "必涨", "必跌", "主力入场第一枪", "出货日", "行情结束", "T0 执行卡", "T0买入价", "T0卖出价" and others listed in schema/v1.py.

## 选股日报格式 (pool briefing / daily report)

当用户要求批量分析多只股票时，输出选股日报。脚本入口: `pool_briefing.py`。

格式：竖排，每只 2-3 行，按推荐买入/重点关注/暂时不看分组。

  蓄势 持股观望 结构强 量价健康 EXPMA7/10 共振6/10
  买49.50 压54.80 损47.20

🥈 禾望电气 601899.SH 18.60（+2.10%）
  蓄势 持股观望 结构强 筹码锁定 EXPMA6/10 共振4/10
  买17.80 压19.50 损17.20

重点关注（2只）

1 恩捷股份 45.20（-0.80%）
  转弱 持股观望 结构强 量价健康 量价弱 EXPMA3/10
  买43.50 压47.00 损42.80
  等转强

2 融捷股份 46.80（-1.20%）
  修复 持股观望 结构强 筹码锁定 量价弱 EXPMA4/10
  买44.50 压49.00 损43.50
  ⚠️ 融合建议减仓

暂时不看（3只）

  震荡 持股观望 结构弱 MACD零轴下 均线空头

仓位：天齐10% 禾望8% 其余0 总仓≤3成
```

每只票 2-3 行结构：
1. 排名 + 名称 + 代码 + 现价（涨跌幅%）
2. 阶段 + 融合动作 + 亮点信号 + 风险信号 + EXPMA评分 + 共振评分（如有）
3. 买X 压X 损X（推荐买入/重点关注必须有；暂时不看可省略）
4. 空行分隔

推荐标签：
- 亮点：结构强/量价健康/筹码锁定(X%)/MACD零轴上/均线多头/融合看多
- 风险：结构弱/量价弱/MACD零轴下/均线空头/均线不明/融合空仓/融合减仓
- EXPMA 趋势通过评分反映（多头排列高分、空头排列低分），不在标签中重复

规则：
- 按融合加权分数从高到低排序
- 排名用 🥇🥈🥉 或数字（3以后用数字）
- 暂无信号时该行省略（不显示 "-"）
- 移动端竖排友好：无表格、无加粗、无水平线、无 Markdown 标题
- 主力评分 15 分制不在此处展示（单票分析时显示）

- 移动端友好：无表格、无加粗、无水平线、无 Markdown 标题
