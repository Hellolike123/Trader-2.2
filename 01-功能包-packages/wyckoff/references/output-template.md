# 威科夫输出骨架（与 render 同源）

微信安全：无 `#` / `**` / `|` 表格 / `---`。并列用全角 `｜`。

## 单票 B·中剪卡（默认 `--target`）

与 `render_wyckoff_slim` 同源。

```
{名}（{码}）｜现价 {price}
周线：{偏多|偏空|中性}｜{大阶段短句}｜{可盯小波段|慎做|先别做}
日线本波：{本波短句}
入池：{建议入池|暂不建议入池（短因）|结构偏空，暂不建议入池}

🧭 周线 · 大阶段
  {周线一句话：主侧 + 大阶段 + 区间/门禁}
  灯
  {●|○} SC（卖力高潮）{price?}
  {●|○} AR（自动反弹）{price?}
  {●|○} ST（二次测试）{price?}
  {●|○} LPS（最后支撑点）{price?}
  {●|○} SOS（强势信号）{price?}
  或周线主侧为派发时：
  {●|○} BC（买力高潮）{price?}
  {●|○} ARE（自动回落）{price?}
  {●|○} SOW（弱势信号）{price?}
  {●|○} LPSY（最后供应点）{price?}
  {●|○} UTAD（派发后上冲）{price?}

⚡ 日线 · 本波
  {日线本波一句话：本波事件 + failed/强弱事实 + 区间/门禁}
  {failed+SOS 时说明：旧底事实与本波强势事实并列，不按顺序推进读}
  灯
  {●|○} SC（卖力高潮）{price?}
  {●|○} AR（自动反弹）{price?}
  {●|○} ST（二次测试）{price?}
  {●|○} LPS（最后支撑点）{price?}
  {●|○} SOS（强势信号）{price?}

🔔 变化
  新亮：…；熄灭：…

🔮 推演
  现在
    周线：{一行}
    日线：{一行}

  若变好
    周线：{一行}
    日线：{一行}

  若变坏
    周线：{一行}
    日线：{一行}

  ⭐ 盯
    周线：{一行}
    日线：{一行}
    本卡不下单；出手/分道看 trader
```

`🔔 变化` 仅当有新亮或熄灭时出现；首次记录、无变化、仅仍亮时整块省略。`🔮 推演` 必出：标签与正文分行、段间空行；每段先周线、后日线。灯必须满灯竖排，一行一灯；默认 B 不写舞台/换幕/当前幕/上一幕。failed 无新强势写 `旧底已废｜待新寻底`；failed+SOS 写 `SOS 强｜旧底已废` 且保留 SC/SOS 同亮解释。L0 / `box_display_mode=none` / 分位种子：区间不得出现分位上下沿数字当箱/雏形。周线 ARE 无 BC 时用派发链，禁止接吸筹 SC。

## 单票完整详析卡（`--full`）

旧完整详析，与 `render_wyckoff_detail` 同源。

```
威科夫详析 — {名}（{码}）｜日线+周线

📊 现况
  现价 x｜周线{偏多|偏空|中性} · {主灯或无主灯}｜日线{…} · {主灯或无灯}｜测算{已给出|均未达 L3}

🔔 变化
  首次记录，暂无对比
  或：新亮：…｜仍亮：…｜熄灭：…

🧭 中线（周线 · 入池看这里）
  一句话：…
  区间：{L0 无成熟箱／无雏形｜L1 雏形…｜L2/L3 箱体…；量度仅 L3}
  失效：…
  入池：{建议入池｜暂不建议入池｜结构偏空，暂不建议入池}

  灯
  ● {CODE}（{中文}）{价?}
  ○ 其他主灯未亮

⚡ 短线（日线 · 盯触发看这里）
  一句话：…
  区间：…
  失效：…

  灯
  ● SC（卖力高潮）…
  ○ AR（自动反弹）未亮
  （默认列 SC/AR/ST/LPS/SOS）

🔮 故事链（以日线推进；周线作背景）

  现在
  …

  若变好
  …

  若变坏
  …

  ⭐ 盯
  …

  入池：…
  说明：本卡不下单；买卖看 trader 门禁；分道仍听 trader

💬 综述
  …
```

`--full` 保留旧详析里的现况、故事链、综述与首次记录变化块；默认 `--target` 不再输出这些长块。

## 单票短卡（`--brief`）

与 `render_wyckoff_card` 同源。

```
威科夫 — {名}（{码}）
现价 {价}
🧭 阶段：{phase_label}｜偏向 {偏多|偏空|中性}
📎 链：威：SC→AR→ST→LPS，还差SOS
📎 失败态链示例：威：SC（Phase A 已失效）
📌 事件：{亮灯事件或无亮灯事件}
📐 TR：下沿x／上沿y｜质量z
⚠ 失效：{invalidation_hint}
🧭 中线阶段：{周线 phase}｜偏向 {…}   ← 有周线时
💬 一句：{summary_oneline}
```

数据不足时：`⚠ …` + `💬 一句：数据不足，仅现价`。

## 池内链排序

```
威科夫池排序（链视角，非分道）
1. {名}｜威：SC→…｜{阶段}
2. …
说明：排序仅看吸筹链进度；出手仍以 trader 分道与 decision_view 为准
```
