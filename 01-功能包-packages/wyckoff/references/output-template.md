# 威科夫输出骨架（与 render_wyckoff_card 同源）

微信安全：无 `#` / `**` / `|` 表格 / `---`。并列用全角 `｜`。

## 单票结构卡

```
威科夫 — {名}（{码}）
现价 {价}
🧭 阶段：{phase_label}｜偏向 {偏多|偏空|中性}
📎 链：威：SC→AR→ST→LPS，还差SOS
📌 事件：{亮灯事件或无亮灯事件}
📐 TR：下沿x／上沿y｜质量z
⚠ 失效：{invalidation_hint}
🧭 中线阶段：{周线 phase}｜偏向 {…}   ← 有周线时
💬 一句：{summary_oneline}
```

数据不足时：`⚠ …` + `💬 一句：数据不足，仅现价`。

威科夫池排序（链视角，非分道）
