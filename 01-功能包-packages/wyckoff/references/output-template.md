# 威科夫输出骨架（与 render 同源）

微信安全：无 `#` / `**` / `|` 表格 / `---`。并列用全角 `｜`。

## 单票详析卡（默认 `--target`）

与 `render_wyckoff_detail` 同源。

```
威科夫详析 — {名}（{码}）｜日线+周线

📊 现况
  现价 x｜周线{偏多|偏空|中性} · {主灯或无主灯}｜日线{…} · {主灯或无灯}｜测算{已给出|均未达 L3}

🔔 变化
  首次记录，暂无对比
  或：新亮：…｜仍亮：…｜熄灭：…

🧭 中线（周线 · 入池看这里）
  一句话：…
  区间：{L0 无成熟箱／无雏形｜L1 雏形…｜L2/L3 箱体…；量度仅 L3}
  失效：…
  入池：{建议入池｜暂不建议入池｜结构偏空，暂不建议入池}

  灯
  ● {CODE}（{中文}）{价?}
  ○ 其他主灯未亮

⚡ 短线（日线 · 盯触发看这里）
  一句话：…
  区间：…
  失效：…

  灯
  ● SC（卖力高潮）…
  ○ AR（自动反弹）未亮
  （默认列 SC/AR/ST/LPS/SOS）

🔮 故事链（以日线推进；周线作背景）

  现在
  …

  若变好
  …

  若变坏
  …

  ⭐ 盯
  …

  入池：…
  说明：本卡不下单；买卖看 trader 门禁；分道仍听 trader

💬 综述
  …
```

L0 / `box_display_mode=none` / 分位种子：区间不得出现分位上下沿数字当箱/雏形。

## 单票短卡（`--brief`）

与 `render_wyckoff_card` 同源。

```
威科夫 — {名}（{码}）
现价 {价}
🧭 阶段：{phase_label}｜偏向 {偏多|偏空|中性}
📎 链：威：SC→AR→ST→LPS，还差SOS
📎 失败态链示例：威：SC（Phase A 已失效）
📌 事件：{亮灯事件或无亮灯事件}
📐 TR：下沿x／上沿y｜质量z
⚠ 失效：{invalidation_hint}
🧭 中线阶段：{周线 phase}｜偏向 {…}   ← 有周线时
💬 一句：{summary_oneline}
```

数据不足时：`⚠ …` + `💬 一句：数据不足，仅现价`。
