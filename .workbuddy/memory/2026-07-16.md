## 数据源 hang 修复（完成，commit 93ff9c0）

- 根因：tushare_client 的 `available` 只查 token+初始化成功，没验证主机真实可达。
  Mac 上 `fastapic.stockai888.top` 不可达（SYN 无响应、无 timeout）→ SDK 内部无超时 requests 永久 hang。
  `_query_http` 虽有 timeout=30，但走的是 SDK 路径（`func(**params)`），该路径无 timeout。
- 修法：`_probe_reachable()` 独立线程 socket.connect + join 硬超时（DNS/connect 挂死一律判不可达）；
  `TushareClient.__init__` 在 SDK 初始化前先探测 api_url，不可达则整条 Tushare 通道标不可用。
- 验证：沙箱 fastapic 可达→仍走 tushare（行为不变）；模拟不可达（TUSHARE_API_URL=10.255.255.1:9）
  → available=False、get_provider() 干净回退腾讯、3s 内返回不挂死。
