### 关键经验（可复用）
- `data_status` 语义是「数据完备度」（由 missing_sources + 核心 quote 决定），不是「数据质量」（各 bar 内部 partial 标记）。排查 partial 时优先看 `missing_sources`/`source_errors`，而非臆测资金流。

- Python `.pyc` 缓存会掩盖源码修改：诊断与全链路结果不一致时，先 `find ... -name "*.pyc" -delete` 再重跑。
- 排查数据通道 bug 时，用 `resolve_security(target)` 构造真实 sec 调 `load_market_snapshot` 比手写 SimpleNamespace 更准（SimpleNamespace 会绕过真实代码路径，掩盖每日线数量异常等问题）。
